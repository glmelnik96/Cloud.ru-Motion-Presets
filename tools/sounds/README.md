# Звуки библиотеки

Две категории панели. «Звуки» — 740 звуков: 720 из источников и 20 частей дорожек подкаста. «Музыка» — 48 треков: 7 в основной установке и 41 трек стоковой музыки опцией установщика `music` (D24). Решения пользователя от 2026-10-26:
- берём всё;
- права на стоковые паки — на пользователе (D21);
- всё идёт в основной установщик, кроме треков Pond5: они ставятся опцией;
- у музыки своя категория в панели;
- музыка пакетов привязана к шаблонам: компаньоны под галочкой «Музыка» (D14).
  - «Экран вебинара»: с таймером — 5-минутный трек, без таймера — 30-секундный (условие `when` компаньона).
  - «Обложка курса»: интро курсов.
- звуки пакета подкаста привязаны к его шаблонам под галочкой «Звуковые эффекты» (D14, по умолчанию включена): части дорожек, ниже.

## Откуда

| Источник | Что взято |
|---|---|
| Пакеты Cloud.ru | дорожки шаблонов подкаста (плашки, контент, QR-код, о госте, подпись спикера, дисклеймер, заставка), вжухи пакетов, музыка вебинаров, курсов и подкаста |
| Папки звуков на рабочем столе | моушн-SFX, атмосферы, природа, город, бытовые шумы, глитчи |
| Музыкальная папка | 41 трек Pond5 — опция `music` |

Из источников в библиотеку не попали только копии:
- 41 файл с хвостом `_new` — побайтовые копии;
- 8 дубликатов: совпадает декодированный звук или огибающая.

Какой файл каким звуком стал, хранит локальный манифест на ПК сборки: `C:/CRBK/work/sounds/manifest.json` (его пишет `make-manifest.mjs` там же). В репозиторий он не попадает, потому что в нём названия папок и паков. В репозитории — только опубликованный список `library/sounds.src.json`: id, русское название, группа, английское название исходника для поиска, длительность.

## Группы

Группа задаёт и категорию.
- «Звуки»: Фирменные, Переходы, Удары, Подъёмы и спады, Интерфейс, Глитчи, Бумага и скотч, Техно и sci-fi, Атмосферы, Природа, Город и люди, Бытовые.
- «Музыка» — по настроению: Cloud.ru (музыка пакетов), Корпоративная, Технологии, Кинематографичная, Электроника, Энергичная, Спокойная.

Списки — в `process.mjs`, панель повторяет их (`panel/src/core/library.ts`). Тест следит, чтобы они совпадали.

## Названия

- **id** — `SFX_<английское название>`, у музыки — `SFX_Music<…>`.
- **Названия** — по-русски. У серий паков сквозная нумерация: «Удар 1–14» собран из двух паков, «Вжух 1–14» — из трёх источников.
- **Поиск** находит звук и по английскому названию исходника, без префиксов паков.

## Обработка (`node tools/sounds/build-sounds.mjs`)

| Шаг | Как |
|---|---|
| Формат | WAV 48 кГц, 16 бит, с дизерингом. Если каналы совпадают — моно (84 звука) |
| Тишина | обрезается с обоих концов там, где звук после усиления тише −60 dBFS. Перед звуком остаётся 5 мс, после — 50 мс, по краям короткие фейды. Музыку и дорожки шаблонов подкаста не обрезаем: они выровнены по своим 10-секундным композициям |
| Громкость | короткие звуки — −18 LUFS по самому громкому моменту (momentary). Длинные фоны (больше 12 с: атмосферы, природа, город, бытовые, sci-fi, глитчи) — −24 LUFS интегрально. Музыка — −18 LUFS интегрально. Пик не выше −1 dBTP: если упирается в пик, звук остаётся тише цели (150 звуков, в основном щелчки, скотч и бумага — короткие и острые) |
| Длительность | по декодированному звуку. Заголовок MP3 может врать: у одного дождя в заголовке 251 с, а звука — 63 с |

Отчёт по каждому файлу лежит в `C:/CRBK/work/sounds/build-report.json`: усиление, обрезка, громкость до и после. Повторный запуск рендерит заново только то, что изменилось: источник, группу или рецепт (`RECIPE`).

## Части дорожек подкаста (`parts.mjs`)

Дорожка пакета подкаста (9,64 с) озвучивает целую 10-секундную сцену:
1. рамка влетает с ударом (0,25–0,85 с, одинаково во всех дорожках);
2. появляется элемент;
3. под паузой идёт общий фон;
4. элемент уходит;
5. рамка вылетает с ударом.

В библиотеке рамка («Рамка подкаста») и элементы — отдельные шаблоны любой длительности. Поэтому дорожка режется на «появление» и «уход», а шаблон ставит их компаньонами: появление — с начала (`in`), уход кончается вместе с шаблоном (`out`).

| Часть | Откуда | Докуда |
|---|---|---|
| Появление элемента | где элемент начинается в паке (сдвиг из `masters/<id>/ref.json`), но не раньше конца удара рамки, 0,85 с: звуки элемента приходят до 0,37 с раньше, чем в паке, с первого кадра шаблона | конец интро мастера на 1×; последние 0,3 с затухают |
| Уход элемента | за выход мастера плюс 0,3 с фона до него, с плавным входом | тихий момент перед ударом рамки: элемент уже ушёл |
| Рамка | удар влёта, 0–0,95 с; удар вылета, 8,72–9,64 с — из «Текста на плашке_1», по которому собрана «Рамка подкаста» | |

Части режутся из уже собранного файла дорожки, с её громкостью: звуки элемента тише удара рамки, как в паке. Компаньоны ставятся только на скорости 1× (условие `when`); у «Подписи спикера» и «Текста на плашке» — ещё и в стиле «Подкаст». «QR-блок» с двумя кодами берёт звуки левого: дорожка пака «QR_код_3» почти совпадает с обеими.

Точки резки сняты на ПК сборки 2026-10-26 по огибающей дорожек (RMS по 50 мс), движению превью пака и превью мастеров. На слух не проверены.
