# D19. Числа канона движения — на подпись

**Что это.** Правило для каждого типа M1–M12 подписано 2026-10-05 в `phase0-decisions.md` (раздел D19): кривая пакета как стиль (2) или одна кривая (1). Здесь — сами числа: кривые, длительности, задержки. После подписи они идут в `brand/tokens.json` (раздел `motion`), а оттуда — в «Фирменные кривые» и брендовые `.ffx`.

**Откуда числа.**
- JSX-дампы пакетов: `docs/research/motion/` — `segments.json.gz` и `expressions.json`, выемка `npm run materials` на ПК сборки 2026-10-06;
- места, подсказанные локальным агентом: `docs/research/materials-reply-2026-10-06.md`, раздел 3;
- копии `*_conv` не считаются: они повторяют исходные пакеты.

**Как читать.**
- Кривая — cubic-bezier `x1,y1,x2,y2`, как в CSS и в «Фирменных кривых».
- Для AE она равна паре ключей со скоростью 0: исходящее влияние = `x1`, входящее = `1 − x2`. Пример: `0.33,0,0,1` — out 33 %, in 100 %.
- Кадры — при 25 fps (D2). Тайминги SMM-композиций с 24 fps пересчитаны по секундам и округлены до кадра.
- «Задержка» — сдвиг старта соседнего слоя (лесенка).

**Что подписать.** Колонку «Решение» в таблице внизу: «да» или поправку. Отдельный выбор нужен в трёх местах: M5, M9 и M10 (вебинары).

## Что ещё нужно до `tokens.json`

1. **Пути масок и фигур.** Кривые M4 и портала M10 считаются по одним влияниям, когда скорости 0. В `tools/dump/motion.mjs` это исправлено (`progressBezier`), и сводка теперь отделяет паузы. Нужен повторный `npm run materials` на ПК сборки (4 с): после него M4 станет окончательным по частоте.
2. **Подпись.** После неё облако вносит раздел `motion` в `brand/tokens.json` в таком виде:

```json
"motion": {
  "fps": 25,
  "styles": {
    "titles":  { "plateIn": { "frames": 20, "bezier": [0.33, 0, 0, 1] }, "plateOut": { "frames": 20, "bezier": [1, 0, 0.67, 1] }, "stagger": 1 },
    "podcast": { "plateIn": { "frames": 23, "bezier": [0.73, 0, 0.25, 1] }, "plateOut": { "frames": 18, "bezier": [0.77, 0, 0.2, 1] } }
  },
  "M6": { "keys": [{ "t": 0.333, "v": -90, "out": [11930.136, 0.541] }, { "t": 1, "v": -3.612, "in": [28.415, 34.504], "out": [27.418, 19.152] }, { "t": 1.6, "v": 0, "in": [0, 9.877] }] }
}
```

Пары `[скорость, влияние %]` — как в AE (`KeyframeEase`), чтобы `.ffx` и «Фирменные кривые» ставили ключи без пересчёта.
