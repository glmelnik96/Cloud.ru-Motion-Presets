# Видео-референсы эффектов

Здесь лежит то, что нужно, чтобы изучить чужой эффект и повторить его в шаблонах, `.ffx` или в панели: кадры, склейки, ход движения. Видео сюда не кладутся: это чужие работы, они живут в `<work>/refs/` на ПК сборки.

## Как прислать

Любым из трёх способов, с короткой заметкой, что нравится и где (таймкоды):

1. **Ссылкой** в чате — YouTube, Vimeo, Behance, Instagram, Telegram, прямой файл.
   - Облако само ссылки не скачивает: сеть облачной сессии закрыта для видеосайтов (proxy 403).
   - Ссылку облако записывает в `refs.json`, скачивает агент на ПК сборки: `npm run refs -- fetch` через `yt-dlp`.
2. **Файлом** на ПК сборки — в `C:/CRBK/work/refs/<slug>.mp4`, затем `npm run refs -- add C:/CRBK/work/refs/<slug>.mp4 --slug <slug>`.
3. **Коротким файлом в ветку** — до 20–30 МБ, в `docs/research/refs/_inbox/`. Облако разберёт его само и удалит из ветки после разбора.

## Что делает разбор

`npm run refs -- analyze --slug <slug> [--strip <начало>,<длина>] [--every <сек>]` (`tools/refs/refs.mjs`) кладёт в `docs/research/refs/<slug>/`:

| Файл | Что это |
|---|---|
| `probe.json` | кадр, частота, длительность, кодек, есть ли звук |
| `sheet.jpg` | 16 кадров по ролику (или каждые `--every` с) с таймкодами — общий вид |
| `cuts.json`, `cuts.jpg` | склейки (scene > 0.3) и первый кадр после каждой |
| `motion.json` | энергия движения по кадрам (средняя разница с предыдущим кадром, 0…255) и отрезки, где что-то движется, без склеек — сколько длится движение |
| `strip-<t>.jpg` | каждый кадр короткого отрезка с номерами — по нему видно кривую движения кадр за кадром (вход, перелёт, доезд) |
| `notes.md` | разбор: что нравится, что движется и как, как повторить |

## Как облако изучает и что получается

1. По `sheet.jpg` и `cuts.jpg` — что в ролике и где нужный эффект.
2. По `motion.json` — длина движений в кадрах.
3. По `strip-*.jpg` — форма кривой. Положение объекта по кадрам облако мерит само, по пикселям кадров, и сводит к cubic-bezier, как кривые D19 в `brand/tokens.json`.
4. В `notes.md` облако пишет, чем это делается:
   - в After Effects — ключи и кривая, выражение, эффект, маска, шейп;
   - в Premiere — Motion, Crop, эффекты, MOGRT;
   - и подходит ли это для панели: кнопкой «Движения», «Монтажа» или «Эффектов» (`.ffx`), или как шаблон библиотеки.
5. Если эффект нужен — предложение на подпись: где он будет в панели и какие у него числа. Потом сборка и живая проверка на ПК сборки.

Когда нужна точность выше, чем дают кадры, — например, точный ход перелёта, — агент снимает плотную полосу кадров (`--strip`) в полном размере.
