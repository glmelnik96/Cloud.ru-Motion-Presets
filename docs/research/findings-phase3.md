# Находки фазы 3 (панель BrandKit), 2026-10-05 … 2026-10-07

Здесь собрано всё, что выяснилось о программах, платформе и пакетах, пока строилась панель: факты, на которые опираются код и решения. Подробности и доказательства — по ссылкам. Ход работ — в плане 3 (`docs/superpowers/plans/2026-10-05-phase3-panel.md`).

Проверено на ПК сборки: Windows, AE 26.5 (26.5x89), Premiere 26.5.2, Media Encoder 26, Node 24. Mac пока не проверялся.

## After Effects

| Находка | Что из этого следует | Где |
|---|---|---|
| В ExtendScript обычный объект наследует члены-операторы (`'-'`, `'+'`…): `esc['-']` даёт функцию, и JSON движка падает на строке с дефисом | Строки экранируются по кодам символов; `BK.call` вызывает только собственные функции адаптера | план 3, установщик 0.1.1–0.1.2 |
| Импорт `.aep` или футажа внутри `beginUndoGroup` может дать «Undo group mismatch», и один Ctrl+Z снимает не всё | Все импорты идут до группы отмены, в группе — только слои (0.1.7) | план 3, T2/T3 |
| `app.executeCommand(16)` (Undo) из скрипта отмену не выполняет | Отмена проверяется из интерфейса | план 3, живой прогон |
| `applyPreset` действует на все выделенные слои; без выделения создаёт новый солид | Панель отказывает без выделения (S4) | `effects.ts` |
| Настройки H.264 в Output Module скриптом не задать: скрипт задаёт только Resize и «Use this frame rate» | Брендовые шаблоны «CR …» собраны вручную в `CR_BrandKit.aom`, пользователь загружает его один раз | P21, `docs/research/export/ae-om.json` |
| Повторная загрузка `.aom` пропускает шаблоны с тем же именем | Загружать ещё раз безопасно | P21 |
| `aerender` работает при открытом AE и не трогает его очередь; видит только сохранённый файл проекта | «В фоне» сохраняет проект, элемент очереди сохраняется с проектом и убирается из открытой очереди | P20, `export-recheck.json` |
| Временные затраты: Render Queue на 10 с FullHD — 2,6 с; `aerender` — 6,8 с, из них ~4 с запуск | По умолчанию Render Queue | `timings.json` |
| AE 26.1+ портит пути вывода не из ASCII | Рабочая папка `<work>` только ASCII (`tools/lib/work.mjs`); файлы с кириллицей в имени склеиваются вне `workPath` | `work.mjs`, `style-pack.mjs` (исправлено 2026-10-07) |
| Ключевой кадр со скоростью 0 и влияниями — ровно cubic-bezier `(out, 0, 1 − in, 1)`; у пространственного свойства одна запись ease, у Scale — по одной на измерение | «Фирменные кривые» ставятся влияниями, по числу измерений | `ease.ts`, `A.applyEase` |
| Путь маски и фигуры AE анимирует по прогрессу 0…1; скорости ключей — шум до 1e-3 | Кривая пути считается по одним влияниям | `motion.mjs`, `materials-reply` |

## Premiere Pro 26.5

| Находка | Что из этого следует | Где |
|---|---|---|
| `importMGT` только перезаписывает: свободную дорожку надо найти самим | MOGRT — на нижнюю свободную с V2, нет — новая дорожка через QE (P2) | S5, P2 |
| `.epr` задаёт кадр и fps сам, секвенция их не перебивает | Пресеты пересохранены в 25 к/с (P18), список пресетов отбирается по кадру (P22) | `pr-epr.json` |
| Очередь AME: `encodeSequence` + `startBatch` возвращается за миллисекунды, сам AME запускается ~6 с; `exportAsMediaDirect` держит Premiere до конца | По умолчанию — очередь AME (P19) | `timings.json` |
| Размер кадра клипа — только из метаданных проекта, `Column.Intrinsic.VideoInfo` («1920 x 1080 (1.0)») | `selectedClip` читает его оттуда | S7, `fit.ts` |
| Позиция Motion бывает в долях кадра | Определяется по значению; панель пишет в том же виде | S7 |
| Crop и Fast Blur ставятся только через QE (`addVideoEffect`) по имени эффекта, а имя зависит от языка интерфейса | Панель перебирает имена: Crop / Обрезка / Обрезать, Fast Blur / Быстрое размытие | `fit.ts`, `edit.ts` |
| **Импортированные медиа Premiere держит открытыми до выхода из программы.** Не помогают `closeDocument`, `setOffline`, 90 с ожидания | Проверка переноса проекта — после перезапуска Premiere (`--transfer`); копия каждый раз в новую папку | `premiere-transfer-reply`, `transfer.mjs` |
| `app.openDocument(path, true, true, true)` — третий аргумент `true` отключает поиск файлов по относительным путям, клипы остаются у старых | Стенд открывает с `false`, как интерфейс | `9e5e839` |
| `qe.project.getVideoEffectByName()` возвращает объект для любой строки (промах — с пустым именем) | Промах проверяется по пустому имени | `addEffect` |
| Скриптом нельзя: применить пресет эффекта, создать маску эффекта, создать корректирующий слой (`newTransparentVideo` — «Illegal Parameter type»), удалить эффект через QE (`removeEffect` роняет eval) | «Размыть поля» сделано копией клипа с Crop над клипом с Fast Blur | `blur-and-captions.json` |
| В 26.5 «Gaussian Blur» — новый эффект (`AE.Impact_Blur_FX`, Amount); классический — «Gaussian Blur (Legacy)»; Fast Box Blur нет | Размытие полей — Fast Blur | `blur-and-captions.json` |
| Размытие в Premiere идёт в линейном свете; по ширине ядра Fast Box Blur 15×3 в 4K ≈ Fast Blur 38, 7,5×3 в 1080p ≈ Fast Blur 20 | Числа `BLUR_FIELDS` | `edit.ts` |
| Пользовательские пресеты эффектов на ПК сборки при запуске не читаются — даже собственный файл Premiere; Import Presets действует до конца сессии | `.prfpset` не годится для доставки; путь — кнопка панели | `premiere-transfer-reply` |
| Маска эффекта в `.prfpset` — SubComponent `AE.ADBE AEMask2`; вершины — в долях кадра, двоичным блоком с `Checksum` неизвестного алгоритма | Генерировать пресеты нельзя, пока неизвестна контрольная сумма | `blur-preset-mask.xml` |
| `createCaptionTrack(srt, 0, CAPTION_FORMAT_SUBTITLE)` работает, но назначить стиль нечем: в DOM нет `captionTracks`, у метода нет аргумента стиля, у субтитра свой `FormattedTextData` | Стиль приносит панель, выбирает монтажёр (Track Style) | `blur-and-captions.json` |
| `.prtextstyle` — UTF-8 XML `PremiereData`; оформление — base64 в «Source Text», шрифт записан только PostScript-именем; `importFiles` приносит его в проект за 0,4 с | `CRS_SubtitleStyle` в библиотеке, `importTextStyle` | `captions-style-sample.txt` |
| Интерлиньяж в стиле субтитров — сдвиг от автоматического, а не абсолютное значение | 36,8 из пакета не переносится; оставлено 0 | `premiere-transfer-reply` |
| CEP-панель не поднимается, пока Premiere на стартовом экране или за другими окнами | Стенд открывает проект и выводит Premiere вперёд | `premiere-transfer-reply` |
| `app.newProject` может оставить `app.project` на старом проекте до конца eval | Новый проект открывается `openDocument` | `blur-and-captions.json` |

## CEP, Node, Windows

| Находка | Что из этого следует | Где |
|---|---|---|
| Несколько панелей делят один движок ExtendScript хоста: старая панель перезагружает свой пакет хоста | Каждый вызов сверяет `BK.version`, при чужом пакете мост грузит свой и повторяет (0.1.6) | `bridge.ts` |
| Preact запускает эффекты после отрисовки: старт мог кончиться раньше подписки интерфейса | Хук берёт состояние сразу после подписки (0.1.9) | план 3 |
| `fs.cpSync` на Node 24 под Windows падает с 0xC0000409 | Копирование папок — своим кодом (`copy-tree.mjs`) | 0.1.4 |
| `require.resolve('vitest/vitest.mjs')` на Node 24 упирается в `exports` пакета | Путь к CLI берётся напрямую | `live.mjs` |
| `explorer.exe` разбирает строку сам и ждёт `/select,"путь"`, а Node берёт в кавычки весь аргумент | `windowsVerbatimArguments` (0.1.16) | `services/export.ts` |
| Git из оболочки агента не видел `~/.ssh`: путь профиля с кириллицей уходил в ssh в CP1251 | `GIT_SSH_COMMAND` с явными путями ключа | `materials-reply` |
| После прогонов остаются десятки осиротевших `CEPHtmlEngine` | Перед перезапуском хоста стенд их закрывает | `premiere-transfer-reply` |

## Облачная среда

- Сеть облачной сессии закрыта для видеосайтов (YouTube, Vimeo: proxy 403). Ссылки на референсы скачивает агент на ПК сборки (`npm run refs -- fetch`); короткие файлы можно положить в ветку (`docs/research/refs/README.md`).
