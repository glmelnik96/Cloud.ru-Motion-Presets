# Старая панель brandcolors (D23)

Источник: `Documents/AE_color-picker`. Панель не запускалась. Ниже — что делает код, не живой прогон.

Меню панели: Window → Extensions → Brand Colors. Идентификатор расширения `com.example.brandcolors`. Хост — только After Effects.

## Палитра

Поставка — `client/colors.json`. Если рядом с расширением есть `user-colors.json`, он заменяет поставку (`client/index.js`, `loadColors`, строки 91–98). На этой машине оба файла совпадают.

| id | Название в панели | HEX |
|---|---|---|
| green | Green | `#26D07C` |
| graphite | Graphite | `#222222` |
| white | White | `#FFFFFF` |
| gray | Gray | `#F2F2F2` |
| yellow | Yellow | `#CFF500` |
| purple | Purple | `#A068FF` |
| blue | Blue | `#C0E0FC` |

Семь HEX совпадают с базовой палитрой `brand/tokens.json` → `color.base`. Имя `#222222` другое: в панели Graphite, в токенах ключ `black` и роль «текст, тёмная подложка». Ролей у старой панели нет, названия английские.

Расширенной палитры (aquamarine, ultramarine, magenta, carrot, coral) в панели нет.

Палитру можно переименовать, перекрасить, переставить, добавить и удалить. Save пишет `user-colors.json`. Reset удаляет его и возвращает `colors.json`.

## Что красит

Кнопка Apply вызывает `applyColorFromHex` (`host/index.jsx`, строки 29–130).

На каждый выделенный слой:

- ищет эффект Fill (`ADBE Fill`) и, если его нет, добавляет;
- ставит цвет единственного цветового свойства эффекта через `setValue([r, g, b, 1])`.

Альфа всегда 1. Родные свойства не трогаются: заливка и обводка шейпа, цвет солида в Solid Settings, заливка и обводка текста, Tint и прочие эффекты. Уже стоящий Fill переиспользуется, второй не добавляется.

Одно действие на все выделенные слои, группа отмены `Apply Brand Color`.

## Ключи, выражения, выделение

Код не смотрит ни на ключи, ни на выражение. Всегда `setValue` внутри `try/catch` (строки 104–116). Своего `setValueAtTime` нет. Если `setValue` бросает ошибку, слой пропускается, текст исключения попадает в строку статуса.

Без композиции: «Open a composition to apply color.» Без выделенных слоёв: «Select at least one layer to apply color.» Объект без `property` (выделенное свойство, не слой) пропускается с текстом «Skipped a non-layer selection.» Отдельного режима «красить выделенные свойства» нет.

## Чего нет в новой вкладке «Цвета»

Есть в старой панели и нет во вкладке 0.1.11:

- пипетка по всему экрану (`EyeDropper`) и копирование HEX по клику на образец;
- правка палитры: свои цвета, имена, порядок, `user-colors.json`, сброс к поставке;
- поле HEX и системный color picker;
- применение через эффект Fill на любой слой, который принимает эффекты (футаж, текст, шейп — одним способом);
- самообновление с GitHub.

Есть во вкладке и нет в старой панели:

- отдельные цели «Заливка», «Обводка», «Текст»;
- родная заливка и обводка шейпа, цвет солида, заливка текста;
- сохранение альфы цвета шейпа;
- ключ на текущем времени, если свойство уже анимировано;
- выражение не перезаписывается и называется в предупреждении;
- предупреждение, что солид общий, и что у слоя нет нужного свойства;
- роли цветов из токенов; палитра только базовая, без правки.

Кнопки «заливка и обводка сразу» нет ни там, ни там. Обводку текста старая панель не красит. Новая тоже красит только заливку текста.
