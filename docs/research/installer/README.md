# Отчёты установок

Сюда пишутся отчёты проверки установщика на машине: `windows-<версия>.json`, `mac-<версия>.json` — коды выхода, вывод установщика, карантин на Mac, что видно в программах. Сводка контрольной точки называет последние из них.

В репозиторий они не попадают (`.gitignore`): в них пути машины (решение пользователя 2026-10-26).
