# Задание локальному агенту: T2/T3 и компаньоны в панели 0.1.5

**От кого:** облачная сессия, ветка `claude/determined-cannon-eum3ei`.

**Где:** ПК сборки.
- AE 26.5 и Premiere 26.5.2.
- Панель BrandKit Dev: CDP 8094 в AE, 8096 в Premiere.
- ffmpeg в PATH.
- Собранная «Подпись спикера» в `C:/CRBK/work/build/TTL_LowerThird`.

**Зачем.** Панель 0.1.5 вставляет файлы T2/T3 и компаньонов шаблонов по spec §6.1:
- петли с интро и аутро, повторённые до длины;
- переход, выровненный маркером полного перекрытия по склейке;
- стилл;
- звук;
- подложку #222222 под петлю на прозрачном;
- у шаблона — фон под ним и звук по `placement`.

В облаке это проверено только на фейках объектных моделей. Нужен прогон в настоящих хостах.

Настоящих петель и звуков в библиотеке ещё нет, поэтому прогон берёт синтетический набор. `tools/panel/media-fixtures.mjs` делает его ffmpeg-ом в `C:/CRBK/work/panel-live/media/`:
- зелёный квадрат на прозрачном (PNG в MOV);
- шторку на 25 кадров;
- сетку PNG;
- синус 0,8 с.

У подписи спикера в этом наборе два компаньона: фон `BG_Arrows` под ней и whoosh в конце. Кодек и вид роликов — не предмет проверки: проверяется, куда и как панель их ставит.

Что из этого ещё не подтверждалось на живом хосте, а значит проверяется впервые:
- **Premiere**:
  - `app.project.importFiles` в бин;
  - `ProjectItem.getInPoint/getOutPoint` как длина файла;
  - `Track.overwriteClip(item, секунды)` на видео- и аудиодорожке;
  - обрезка стилла длиннее его 5 с по умолчанию;
  - QE `addTracks(0, n, 1, 1, a)` для аудиодорожки;
  - `Sequence.getOutPointAsTime`.
- **AE**:
  - `FootageItem.mainSource.loop`;
  - `layers.addSolid`;
  - `moveAfter`;
  - слой звука.

## Шаги

1. Подготовка:
   ```bash
   git pull origin claude/determined-cannon-eum3ei
   npm ci
   npm test
   ```
   Всё должно быть зелёным. Тест `tests/tools/media-fixtures.test.mjs` сам собирает синтетический набор, если в PATH есть ffmpeg.
2. Перезапустите AE и Premiere, откройте BrandKit Dev в обоих. В AE сохраните или закройте свой проект: прогон создаёт свой `C:/CRBK/work/panel-live/ae/media_live.aep` и не трогает чужой несохранённый проект.
3. Живой прогон:
   ```bash
   node tools/panel/live.mjs --host ae --media
   node tools/panel/live.mjs --host pr --media
   ```
   - Первый запуск делает набор и каталог. Ждём строку `synthetic pack built: 11 files made` (во втором хосте — 0 files made).
   - Отчёты пишутся в `docs/research/panel-live/ae-media-report.json` и `pr-media-report.json`.
   - Случаи (по композиции или секвенции 1920×1080 25p на каждый):

   | Случай | Что вставляется | Чего ждём |
   |---|---|---|
   | `loop` | `BG_Arrows` с плейхеда 2 с, конец рабочей области (out-точки) 20 с | длина 18 с: интро 2–3, петля 3–19, аутро 19–20; петля повторена 2 раза (AE — Interpret Footage → Loop 2×; Premiere — 2 клипа встык); подложка #222222 под петлёй (AE — солид, Premiere — PNG на дорожке ниже) |
   | `reuse` | тот же фон ещё раз с 30 с на 12 с, без подложки | ничего не импортировано второй раз |
   | `transition` | `TRN_StepWipe` с плейхеда 12 с | Premiere: на V1 стенд кладёт клипы со склейкой в 10 с, переход начинается в 9,52 с (кадр 12 — на склейке); AE: начало 11,52 с (кадр 12 — на текущем времени) |
   | `still` | `BG_DotGrid` на 8 с | стилл держится 8 с |
   | `sound` | `SFX_WhooshIn` с 5 с | Premiere — на A2, AE — слой звука, 0,8 с |
   | `companions` | «Подпись спикера» с 2 с | фон `BG_Arrows` под шаблоном на его 6 с (Premiere — дорожка ниже MOGRT, AE — слои сразу под слоем шаблона), whoosh кончается вместе с шаблоном (начало 7,2 с) |

   Во всех случаях файлы лежат в `C:/CRBK/work/panel-live/<host>/Cloud.ru BrandKit/<id>@1/`, и слои или клипы играют эти копии, а не библиотеку.
4. **Вручную в AE — отмена.** Сразу после прогона, не трогая проект, откройте композицию `BK media companions`. Последняя вставка прогона — «Подпись спикера» с компаньонами: слой шаблона, три слоя фона и слой whoosh. Поставьте фокус на таймлайн и нажмите Ctrl+Z один раз: все пять слоёв должны сняться одним шагом. Предупреждений «Undo group mismatch» быть не должно.
5. **Вручную в Premiere — посмотреть таймлайн.** Откройте `media_live.prproj`, секвенции `BK media loop` и `BK media companions`:
   - стыки петли идут без пропуска кадра;
   - квадрат проходит стык 3 с (интро → петля) без скачка;
   - подложка тёмно-серая (#222222), а не чёрная.

   Сделайте два скриншота таймлайна: `docs/research/panel-live/pr-media-loop.png` и `pr-media-companions.png`.
6. **Форма в настоящей панели** (интерфейс T2/T3):
   ```bash
   node tools/panel/install-dev.mjs --library C:/CRBK/work/panel-live/media/library
   ```
   Перезапустите хосты и в Cloud.ru BrandKit проверьте:
   - у «Фон со стрелками» есть поле длины и галочка «Подложка #222222», она включена;
   - у «Ступенчатая шторка» и «Звук входа плашки» поля длины нет;
   - у «Подписи спикера» есть галочка «Звуковые эффекты»;
   - вставка каждого из этих трёх элементов из интерфейса проходит, внизу «Вставлено».

   Скриншоты: `docs/research/panel-live/<host>-media-form.png`.

   После этого верните обычную библиотеку: `node tools/panel/install-dev.mjs --no-build`, она берётся из `C:/CRBK/work/panel-live/library`.
