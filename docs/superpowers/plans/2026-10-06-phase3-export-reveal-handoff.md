**От кого:** облачная сессия, ветка `claude/determined-cannon-eum3ei`.

**Что изменилось после `f1868b3`:**
- **«Показать в папке».** Explorer получает `/select,"<путь>"`: кавычки только вокруг пути, строка передаётся как есть (`windowsVerbatimArguments`). Раньше Node брал в кавычки весь аргумент, и путь с пробелом открывал «Документы».
