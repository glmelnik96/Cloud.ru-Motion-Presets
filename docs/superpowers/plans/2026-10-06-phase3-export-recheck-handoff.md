## Шаги

1. Обновите ветку, затем `npm test`.
2. Соберите обычную библиотеку и поставьте панель. Пресеты уже лежат в `C:/CRBK/work/build` после `export-pack.mjs`; если нет — повторите шаг 2.3 из `2026-10-06-phase3-export-handoff.md`.
   ```bash
   npm run library:build
   node tools/panel/install-dev.mjs
   ```
   Перезапустите AE и Premiere. В строке состояния — «панель 0.1.15».
3. **Premiere**, вкладка «Экспорт», секвенция 1920×1080 25p с клипом, проект сохранён:
   - «В очередь Media Encoder» на «Вебинар — таймер», дождитесь файла в `Export/`, затем ещё раз. Ждём во второй раз в строке результата `…_WebinarTimer_2.mp4`, а в `Export/` — без файла `_1` от AME. Ждать первый файл нужно потому, что панель видит только файлы, которые уже лежат в папке.
   - «Показать в папке» открывает Проводник с выделенным файлом.
4. **AE**, композиция 1920×1080, проект сохранён:
   - «В фоне (aerender)» → «Сохранить проект и рендерить в фоне». Ждём:
     - строку «В фоне: …», затем «Готово: …» с «Показать в папке»;
     - AE не занят, пока идёт рендер;
     - пункт пользователя в очереди не тронут.
   - Повтор фона — файл `_2`.
   - «Рендерить» — «Показать в папке» работает.
   - **Несохранённый новый проект:** «В фоне» не запускается, сообщение просит сохранить проект. «Рендерить» пишет в «Документы/Cloud.ru BrandKit/Export».
5. Скриншоты фона («В фоне» и «Готово»), строки с `_2` и Проводника — в `docs/research/panel-live/`.
