# Задание локальному агенту: материалы фаз 1–2 из пакетов, перенос проекта, разведка Premiere

**От кого:** облачная сессия, ветка `claude/determined-cannon-eum3ei`.

**Где:** ПК сборки — тот же, где делались архив, рабочие копии пакетов, JSX-дампы фазы 1 (`C:/CRBK/work/dumps`, 162 файла) и мастера.

**Зачем.** Фаза 3 ждёт материалов из пакетов:
- «Фирменные кривые» и брендовые `.ffx` — числа канона движения D19 из JSX-дампов;
- размытие полей подкаста (D11) и стиль «CR Субтитры» (D25) — параметры из пакетов и способ поставить их в Premiere;
- мастера фазы 2 и раздел «Звуки» — опись композиций и звуков.

Скрипты выемки написаны в облаке и проверены на синтетических дампах. Нужен прогон на настоящих данных и ручная разведка Premiere.

**Код панели не чинить — описывать.** Пакеты и архив только читаются. Отчёты — в `docs/research/…`, всё одним или несколькими коммитами в ту же ветку.

## 0. Перед началом

## 1. Перенос проекта — перепроверка

В прогоне части A переименование `Cloud.ru BrandKit` после того, как хост отпустил проект, получило EPERM. Теперь стенд повторяет переименование с растущими паузами (0,5 → 15 с, около 30 с всего). Если папка так и не освободится, он пишет, какой процесс её держит — через `handle.exe` из Sysinternals, если тот есть в PATH.

1. Если можно, поставьте Sysinternals Handle (`handle.exe` в PATH) — это нужно только для диагностики.
2. Запустите:
   ```bash
   node tools/panel/live.mjs --host ae --media
   node tools/panel/live.mjs --host pr --media
   ```
3. В отчётах `*-media-report.json` смотрите строки `transfer:`:
   - `retries` — сколько повторов понадобилось;
   - если упало — текст и строка `held by: …`.
4. После прогона убедитесь, что не осталось папок с суффиксом `.away`.
5. Если перенос прошёл, повторите `npm run panel:checkpoint -- --only media`. Тесты он гонит каждый раз, флаг `--skip-tests` можно добавить. Цель — свежая сводка `docs/research/checkpoint/win-*.md` без провалов.

## 2. Выемка материалов из дампов и пакетов

```bash
npm run materials
```

Это `tools/dump/materials.mjs`. Он читает `C:/CRBK/work/dumps` и рабочие копии пакетов (`packsDir()`, обычно `C:/CRBK/packs`) и пишет четыре папки.

| Папка | Файлы | Что там |
|---|---|---|
| `docs/research/motion/` | `summary.md`, `summary.json`, `expressions.json`, `segments.json.gz` | Каждая пара соседних ключей каждого анимированного свойства: тип свойства, длительность в кадрах, изменение, интерполяция, скорость и влияние ключей AE и эквивалентная кривая cubic-bezier (флаг перелёта). Выражения движения: wiggle, loopOut, `time*k`. В сводке — частые кривые по типам свойств и обрезанные дампером ключи (`truncatedKeys`). |
| `docs/research/looks/` | `effects.json`, `blurs.json`, `text-styles.json`, `fonts.json`, `summary.md` | Все эффекты с параметрами; все размытия с параметрами и типом слоя (корректирующий или нет); все текстовые стили (шрифт, кегль, трекинг, интерлиньяж, заливка, обводка, caps, рамка) с местами; шрифты по пакетам. |
| `docs/research/inventory/` | `comps.json`, `comps.md` | Все композиции: кадр, fps, длительность, рабочая область, маркеры, текстовые слои (будущие поля), вложенные композиции, корневая ли, есть ли Essential Graphics. |
| `docs/research/sounds/` | `inventory.json`, `summary.md` | Все 38 звуков пакетов (32 WAV, 6 MP3): формат, длительность, громкость EBU R128 (LUFS, LRA, true peak), где используются. |

Проверьте и опишите:
- **Размер файлов.** Если `segments.json.gz` больше 20 МБ, не коммитьте его: оставьте в `C:/CRBK/work/materials/` и скажите размер. Остальное коммитьте.
- **Числа на глаз.** Кривые в `motion/summary.md` похожи на правду? Например, у плашки подписи спикера должна быть одна-две частые кривые на всех её отрезках.
- **Ошибки скрипта.** Если упал, приложите текст ошибки и название дампа.
- **`truncatedKeys`.** Есть ли свойства, обрезанные по лимиту ключей, — список.

## 3. Где в пакетах типы движения D19 — подсказка для разбора

Разбирать и классифицировать будет облако, по сводке. Но по пакетам, которые вы знаете по починке фазы 1, напишите в ответе одной строкой на тип, в какой композиции и на каком слое он лучше всего виден. Типы M1–M12 — в `docs/decisions/phase0-decisions.md`, раздел «D19. Канон движения по типам». Например: «M1 — titles / Подпись спикера / слой Плашка, Scale X».

## 4. Размытие полей подкаста (D11) — разведка Premiere

Итог S7: клип корректирующего слоя из шаблонного проекта скриптом не поставить. Запасной путь — `.prfpset`, который монтажёр применяет вручную. Нужно выяснить, как удобнее его доставить.

1. Параметры размытия в пакете подкаста — из `docs/research/looks/blurs.json`: эффект, сила, повтор краёв, маски.
2. В Premiere 26.5 соберите на корректирующем слое такое же размытие (Gaussian Blur с теми же числами). Сохраните его как пресет эффекта «CR Размытие полей» (Effects → правая кнопка → Save Preset), затем экспортируйте в `.prfpset` (Export Preset).
3. Выясните:
   - Где Premiere хранит пользовательские пресеты эффектов (папка профиля в `Documents\Adobe\Premiere Pro\26.0\…`). Подхватывает ли он `.prfpset`, положенный туда файлом при закрытом Premiere, или только через Import Presets?
   - Видит ли QE этот пресет (`qe.project.getVideoEffectByName('CR Размытие полей')`)? Можно ли применить его скриптом к клипу (`qeItem.addVideoEffect(…)`)?
   - Чем Premiere заменяет корректирующий слой в скрипте: можно ли создать Adjustment Layer скриптом или QE в 26.5?
4. Сохраните `.prfpset` в `C:/CRBK/work/materials/premiere/`. В git его не кладите, это файл бренда.

## 5. Стиль «CR Субтитры» (D25) — разведка Premiere

Итог S7: стиль — инструкцией. Нужно понять, что можно сделать файлом и скриптом.

1. Стиль субтитров курсов в пакете — из `docs/research/looks/text-styles.json`. Скорее всего, это пакет курсов: шрифт SB Sans Text, белый текст, плашка `#222222`.
2. В Premiere 26.5 создайте дорожку субтитров (Text → Captions), задайте стиль по этим числам, сохраните как Track Style «CR Субтитры».
3. Выясните:
   - Где хранится стиль: только в проекте, в Libraries, файлом?
   - Можно ли его экспортировать и импортировать в другой проект (Export Text Style / `.prtextstyle`)? Сохраните файл в `C:/CRBK/work/materials/premiere/`.
   - Можно ли скриптом создать дорожку субтитров из `.srt` (`Sequence.createCaptionTrack`) и назначить ей стиль?
   - Есть ли рядом с проектом что-то, что надо переносить вместе с ним?
