## 1. Перенос проекта в Premiere — проверка после перезапуска

Вы нашли, что Premiere 26.5 держит импортированные медиа до выхода из программы. Поэтому стенд теперь делит перенос на два шага:
- **Прогон media** в Premiere только отпускает проект и собирает копию. Копия каждый раз кладётся в новую папку `<work>/panel-live/pr-moved-<время>`, старые удаляются, если их уже отпустили. Что собрано, стенд записывает в `<work>/panel-live/pr-transfer-staged.json`.
- **Проверка** запускается после перезапуска Premiere. Стенд прячет оригиналы и библиотеку, открывает копию, сверяет пути и всё возвращает.

В AE ничего не меняется: перенос по-прежнему целиком проходит в прогоне media.

Шаги:
1. `npm run panel:checkpoint -- --host pr --only media --skip-tests`.
   - В сводке строка «Перенос проекта» для Premiere будет «ждёт перезапуска Premiere» — так и должно быть.
2. Закройте Premiere полностью и убедитесь, что процесса `Adobe Premiere Pro.exe` нет. Запустите Premiere заново, проект не открывайте и откройте панель BrandKit Dev.
3. `npm run panel:checkpoint -- --host pr --only transfer --skip-tests`.
   - Это `node tools/panel/live.mjs --host pr --transfer`, отчёт — `docs/research/panel-live/pr-transfer-report.json`.
   - Сводка дня `docs/research/checkpoint/win-<дата>.md` теперь дополняется, а не перезаписывается: строки, которые прогон не проверял, остаются как были. Если файла дня нет, полная сводка соберётся из прогона полного checkpoint.
4. Если проверка упала с EPERM — пришлите строку `held by:` из отчёта.
5. После прогона не должно остаться папок `.away`.

Цель — свежая сводка Windows, где зелёные все критерии, включая «Перенос проекта» в AE (набор media) и в Premiere (набор transfer). Если удобнее собрать сводку дня заново целиком:

```bash
npm run panel:checkpoint
# перезапуск Premiere
npm run panel:checkpoint -- --host pr --only transfer --skip-tests
```

## 3. Два ручных шага в интерфейсе Premiere

Скрипт этого не умеет: ни QE, ни DOM не создают корректирующий слой, маску эффекта и стиль дорожки. Если интерфейсом может управлять только человек, передайте пользователю шаги 3.1 и 3.2 как есть. Проверки 3.3 потом выполните сами.

### 3.1. Пресет «CR Размытие полей» (D11)

1. Новый проект, последовательность 1920×1080, 25 fps, на V1 любой клип на 10 с.
2. Project → New Item → Adjustment Layer (1920×1080), положить на V2 над клипом.
3. На корректирующий слой — Effects → Video Effects → Blur & Sharpen → **Fast Blur**:
   - Blurriness **20**;
   - Blur Dimensions — Horizontal and Vertical;
   - **Repeat Edge Pixels** — включено.
4. В Effect Controls у Fast Blur — инструмент прямоугольной маски. Маска на весь кадр с отступом **52,5 px** слева и справа и **51 px** сверху и снизу: вершины (52.5, 51) и (1867.5, 1029). Inverted — включено, Mask Feather — 0, Mask Expansion — 0.
   - Проверка: размыты только поля, центр резкий.
5. Правой кнопкой по Fast Blur → **Save Preset…** → имя **«CR Размытие полей»**, тип Scale.
6. Effects → Presets → «CR Размытие полей» → правой кнопкой → **Export Preset…** → `C:/CRBK/work/materials/premiere/CR Размытие полей.prfpset`.
7. Повторить шаги 1–6 для последовательности 3840×2160:
   - Blurriness **38**;
   - отступ 105 и 102 px;
   - имя «CR Размытие полей 4K»;
   - файл `CR Размытие полей 4K.prfpset`.

### 3.2. Стиль «CR Субтитры» (D25)

1. В том же проекте положите на последовательность `probe.srt` из `C:/CRBK/work/materials/premiere/probe`: Text → Captions → Import, или правой кнопкой по `.srt` → Create Captions.
2. Выделите дорожку субтитров → Properties (Essential Graphics):
   - шрифт **SB Sans Text Regular**, размер **35**;
   - трекинг **−32**, интерлиньяж **36,8**;
   - заливка **#FFFFFF**, без обводки и тени, по центру;
   - Background — включён, **#222222**, непрозрачность 100 %, без скругления, отступ по умолчанию.
3. Track Style → **Create Style…** → «CR Субтитры». Затем:
   - Save to Local Styles;
   - добавить в проект;
   - Export Track Style… (если есть) → `C:/CRBK/work/materials/premiere/CR Субтитры.prtextstyle`.
   - Если пункта экспорта нет, скопируйте файл из `Documents/Adobe/Common/Assets/Text Styles`.
4. Кадр с субтитром — `exportFramePNG`, как в разведке — сохраните рядом с `captions-from-srt-default-style.png`: `docs/research/premiere/captions-cr-style.png`.

### 3.3. Что проверить скриптом и руками по готовым файлам

1. **XML пресета.** Откройте `CR Размытие полей.prfpset` и найдите узел маски: имена узлов и параметров, где вершины, где Inverted. Приложите кусок XML с маской в `docs/research/premiere/blur-preset-mask.xml` — без остального пресета, его не коммитить. С этим куском облако сможет генерировать пресеты под любой размер последовательности.
2. **Файл в профиле при закрытом Premiere.** Закройте Premiere и найдите папку профиля: `Documents/Adobe/Premiere Pro/26.0/Profile-<user>/`. После Save Preset там появился `Effect Presets and Custom Items.prfpset` — запишите путь.
   - Удалите из Premiere пресет «CR Размытие полей», закройте Premiere.
   - Положите экспортированный `.prfpset` в профиль: (а) отдельным файлом; (б) если не подхватится — вместо общего файла, сначала сохранив его копию.
   - Запустите Premiere: виден ли пресет в Effects → Presets? Общий файл потом верните.
3. **Импорт стиля скриптом.** В новом проекте выполните `app.project.importFiles(['…/CR Субтитры.prtextstyle'], true, app.project.rootItem, false)`. Появился ли элемент стиля в Project? Виден ли «CR Субтитры» в списке Track Style у новой дорожки субтитров (`createCaptionTrack` из `probe.srt`)?
   - Назначить стиль дорожке скриптом нельзя — это вы уже выяснили. Если импорт работает, панель сможет приносить стиль в проект одной кнопкой, а монтажёр выберет его в списке.
4. **Fast Blur на глаз.** Сравните кадр пресета на 1080p с кадром пакета (`C:/CRBK/work/dumps/podcast` или рендер подкаста): похожа ли ширина размытия полей.
