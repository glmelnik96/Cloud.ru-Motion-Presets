## 1. Перенос проекта в Premiere — проверка после перезапуска

Premiere 26.5 держит импортированные медиа до выхода из программы. Поэтому:
- прогон media в Premiere только собирает копию в новую папку `<work>/panel-live/pr-moved-<время>` и пишет `<work>/panel-live/pr-transfer-staged.json`;
- проверка — `node tools/panel/live.mjs --host pr --transfer` после перезапуска: оригиналы и библиотека прячутся, копия открывается, пути сверяются, всё возвращается.

В AE перенос целиком проходит в прогоне media, как раньше.

1. `npm run panel:checkpoint`
   - Это полная сводка дня. В строке Premiere «Перенос проекта» будет «ждёт перезапуска Premiere» — так и должно быть.
2. Перезапуск Premiere — по разделу выше.
3. `npm run panel:checkpoint -- --host pr --only transfer --skip-tests`
   - Отчёт — `docs/research/panel-live/pr-transfer-report.json`.
   - Сводка дня `docs/research/checkpoint/win-<дата>.md` дополняется, а не перезаписывается.
4. **Если проверка упала с EPERM:**
   - смотрите `held by:` в отчёте;
   - если держит Premiere — его медиа открыты, значит перезапуск не удался: повторите перезапуск и шаг 3, один раз;
   - если держит другой процесс — опишите его, остановите, если это не системный процесс и не программа пользователя, и повторите шаг 3.
5. Проверьте, что нет папок `.away`, а оригиналы `<work>/panel-live/pr/Cloud.ru BrandKit` и библиотека на месте.

**Цель:** все критерии сводки Windows зелёные, включая «Перенос проекта» в AE (набор media) и в Premiere (набор transfer).
