# Задание локальному агенту: вкладка «Эффекты» в AE (панель 0.1.8)

**От кого:** облачная сессия, ветка `claude/determined-cannon-eum3ei`.

**Где:** ПК сборки.
- AE 26.5 с BrandKit Dev (CDP 8094).
- Premiere 26.5.2 — только для шага 4.
- ffmpeg в PATH.
- Собранная «Подпись спикера» в `C:/CRBK/work/build`.

**Зачем.** Панель 0.1.8 применяет фирменный `.ffx` к выделенным слоям в AE (spec §6.1 шаг 7, §7 «Эффекты»):
- один вызов `applyPreset` на все выделенные слои, ключи встают на текущее время, всё в одной группе отмены;
- без выделения панель отказывает до вызова хоста. В S4 AE в этом случае создавал новый солид;
- панель называет слои, к которым пресет не подошёл (например, текстовый пресет на солиде).

Фирменных `.ffx` ещё нет. Как в S4, вместо них взяты пресеты из поставки AE:
- `Text/Animate In/Fade Up Characters.ffx` — за «Подъём текста по словам» (`FX_TextRise`);
- `Transitions - Wipes/Linear Wipe.ffx` — за «Рост плашки по X» (`FX_PlateGrow`).

Генератор синтетического набора копирует их из `C:/Program Files/Adobe/Adobe After Effects 2026/Support Files/Presets`. Если AE стоит в другом месте, задайте `BRANDKIT_AE_PRESETS`.

«Фирменные кривые» не сделаны: чисел кривых D19 ещё нет, они придут из JSX-дампов фазы 1.

## Шаги

1. Подготовка:
   ```bash
   git pull origin claude/determined-cannon-eum3ei
   npm ci
   npm test
   ```
2. Живой прогон AE:
   ```bash
   node tools/panel/live.mjs --host ae --media
   ```
   После случаев медиа прогон создаёт `C:/CRBK/work/panel-live/ae/effects_live.aep` с композицией `BK effects` (текстовый слой `BK Имя` и солид `BK Плашка`) и проверяет:

   | Случай | Выделено | Пресет | Ждём |
   |---|---|---|---|
   | `text` | `BK Имя`, время 2 с | Fade Up Characters | у текста появился аниматор, первый ключ на 2 с |
   | `plate` | `BK Плашка`, 4 с | Linear Wipe | у солида появился эффект, первый ключ на 4 с |
   | `mixed` | оба слоя, 6 с | Fade Up Characters | применён к тексту; предупреждение `PRESET_PARTIAL`: к солиду не применился |
   | `none` | ничего | Linear Wipe | отказ `NO_SELECTION` в панели и в адаптере, новых слоёв нет |

   Ждём строку `effects: stand-in presets found in the AE presets folder` и все проверки зелёными. Отчёт — `docs/research/panel-live/ae-media-report.json`.
3. **Вручную из настоящей панели.**
   1. Установите панель с синтетической библиотекой:
      ```bash
      node tools/panel/install-dev.mjs --library C:/CRBK/work/panel-live/media/library
      ```
      Перезапустите AE.
   2. Новый сохранённый проект в `C:/CRBK/work/panel-live/ae-fx/`, композиция 1920×1080 25p. Добавьте текстовый слой и солид.
   3. Категория «Эффекты»: карточки «Подъём текста по словам» и «Рост плашки по X».
   4. Откройте «Рост плашки по X». Ждём:
      - нет полей формата и длины;
      - подсказка про выделение;
      - кнопка «Применить к выделенным».
   5. Ничего не выделяя, нажмите кнопку. Ждём ошибку «Выделите в композиции слои…», новых слоёв нет.
   6. Выделите оба слоя, поставьте время на 3 с, нажмите кнопку. Ждём «Применено к слоям: …» с обоими слоями и ключи с 3 с.
   7. Ctrl+Z один раз. Ждём: эффект снят с обоих слоёв одним шагом, предупреждения «Undo group mismatch» нет.
   8. «Подъём текста по словам» на оба слоя. Ждём предупреждение, что к солиду пресет не применился.

   Скриншот формы: `docs/research/panel-live/ae-effects-form.png`.
4. В Premiere с той же библиотекой карточек «Эффекты» быть не должно: `.ffx` только для AE.
5. Верните обычную библиотеку: `node tools/panel/install-dev.mjs --no-build`.
