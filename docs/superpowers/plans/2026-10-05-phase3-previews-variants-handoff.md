# Задание локальному агенту: превью по форматам и вариантам (панель 0.1.10)

**От кого:** облачная сессия, ветка `claude/determined-cannon-eum3ei`.

**Где:** ПК сборки — AE 26.5 с BrandKit Dev (8094), Premiere 26.5.2, ffmpeg в PATH, собранные мастера в `C:/CRBK/work/build`.

**Зачем.** Замечание пользователя: у шаблона несколько форматов и вариантов (у «Подписи спикера» — стили «Титры», «Подкаст», «Вебинар»), а превью в форме при их смене не меняется. Превью должно показывать все варианты.

Теперь `tools/masters/preview.mjs` рендерит превью на каждую пропорцию и на каждое значение переключателей, которые меняют вид (`axes` в блоке `preview` файла `masters/<id>/ref.json`):

| Шаблон | Пропорции | Переключатели | Превью |
|---|---|---|---|
| «Подпись спикера» | 16:9, 9:16, 1:1 | стиль (3) | 9 |
| «Логошот с подписью» | 16:9, 9:16 | подпись (3) × тема (2) | 12 |
| «Логотип без подписи» | 16:9, 9:16 | подложка (вкл./выкл.) × тема (2) | 8 |

Файлы называются `preview_<формат>[_<поле>-<значение>…].mp4` и `poster_….jpg`. Вертикальные превью вписаны в квадрат 480 px по высоте. Превью карточки (`preview.mp4`, `poster.jpg`) — копия варианта по умолчанию.

Форма в панели показывает превью той же пропорции, что выбранный формат, и с теми же значениями переключателей. «Фон», «Сторона», «Скорость» и «Размер текста» в превью не отражаются: показан вариант по умолчанию.

## Шаги

1. Подготовка:
   ```bash
   git pull origin claude/determined-cannon-eum3ei
   npm ci
   npm test
   ```
2. Рендер. AE должен быть открыт, его проект сохранён или закрыт.
   ```bash
   node tools/masters/preview.mjs --item TTL_LowerThird
   node tools/masters/preview.mjs --item LOGO_Shot
   node tools/masters/preview.mjs --item LOGO_Mark
   ```
   - Ждём по строке `OK …/preview_<имя>.mp4 …` на каждое превью: 9, 12 и 8. В конце — `OK card preview = <имя>`.
   - Запишите, сколько времени занял каждый шаблон.
3. Скопируйте все `poster_*.jpg` в `docs/research/previews/variants/<id>/` (MP4 не нужны) и посмотрите их. Проверьте:
   - стиль, подпись, тема и подложка действительно разные;
   - вертикальные кадры не обрезаны;
   - нет пустых или чёрных кадров.
4. Каталог и панель:
   ```bash
   npm run library:build -- --out C:/CRBK/work/panel-live/library
   node tools/panel/install-dev.mjs
   ```
   - Ждём `OK … 3 items, 77 files`: 13 файлов шаблонов, 3 × 2 файла карточек и 29 × 2 файла превью.
   - Затем перезапустите AE и Premiere.
5. Проверка настоящей панели:
   ```bash
   node tools/panel/ui-check.mjs --host ae
   node tools/panel/ui-check.mjs --host pr
   ```
   Новая проверка — `form preview: «Подкаст» shows its own preview`.
6. Вручную в обеих панелях:
   - **«Подпись спикера»:** переключите стиль (Титры → Подкаст → Вебинар) и формат (16:9 → 9:16 → 1:1). Превью меняется каждый раз и совпадает с выбором.
   - **«Логошот с подписью»:** подпись и тема.
   - **«Логотип без подписи»:** подложка и тема.
   - Скриншоты формы — по одному на шаблон в двух разных вариантах: `docs/research/panel-live/<host>-preview-<id>-<вариант>.png`.
