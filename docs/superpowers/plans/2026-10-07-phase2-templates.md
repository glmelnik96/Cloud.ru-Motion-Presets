## Главная помеха: дампы не в облаке

Мастера строятся из чисел JSX-дампов пакетов (`masters/<id>/resolve.mjs` читает `C:/CRBK/work/dumps`). В облаке дампов нет, есть только выемки: `docs/research/motion|looks|inventory`. По ним кривые и тайминги известны, а геометрии слоёв (позиции, размеры плашек, маски, тексты) нет.

**Предлагается:** агент кладёт дампы исходных пакетов в ветку сжатыми — `docs/research/dumps/<slug>/<compSlug>.json.gz`.
- Пакеты: logo, titles, podcast, smm, courses, webinars, без `*_conv` и fixture.
- Объём: 54,8 МБ JSON, после gzip ожидается 5–8 МБ.

`tools/dump/model.mjs` научится читать `.json.gz`, а `resolve.mjs` — брать дампы из репозитория, если нет рабочей папки. Тогда облако считает параметры мастеров само и проверяет их тестами, а агент только собирает в AE, сверяет и упаковывает.

Внутри дампов — тексты пакетов, в том числе имена гостей подкаста. Репозиторий приватный, выемки с этими текстами уже в нём.

## `.ffx`: файлы или риги панели

Сохранить `.ffx` скрипт AE не может: «Save Animation Preset» есть только в интерфейсе. Поэтому есть два пути:
- **А. `.ffx` руками:** агент собирает движение в AE и сохраняет пресет через интерфейс (управление экраном). Работает без панели, но каждое изменение — снова руками.
- **Б. Риги панели:** движение строит скрипт панели на выделенных слоях — как «Цвета» и «Движение». Пишется и проверяется в облаке, остаётся живым, числа берутся из `tokens.json`. `.ffx` для тех, кто без панели, можно потом снять из рига тем же агентом.

**Рекомендация — Б.** Для M7, M9, M11 (выражения) и M6, M12 (ключи логотипа) риг точнее `.ffx`. Решение пользователя.

**Решено 2026-10-20: Б** (пользователь: «B»). Риги — раздел «Движения» во вкладке «Движение» AE, над «Кривыми».
- **Как работает.** Выделить слои, нажать движение. Ключи встают от текущего времени, длительности и кривые — из канона D19 (`brand/tokens.json`, кадры при 25 к/с), одна отмена на всё.
  - Значения считаются от текущего состояния слоя: «вход» приходит в него, «выход» уходит из него.
  - Несколько слоёв идут лесенкой, если она есть в каноне, сверху вниз.
  - Слой не того типа пропускается с причиной.
- **Ядро** (`panel/src/core/rigs.ts`) переводит канон в операции, **адаптер** (`panel/host/ae-rigs.jsx`) только пишет их.
- **Движения:**

| Тип | Что делает риг | Слои |
|---|---|---|
| M1 плашка по X | Scale X: 0 ↔ текущий; стили «титры», «подкаст», SMM, «логошоты» (выход логошота — по Y) | любые; растёт от опорной точки |
| M2 подъём текста | аниматор «BrandKit M2»: Position на высоту блока ×1,15, селектор по словам или строкам, Start 0 → 100 (выход 100 → 0); шесть стилей канона | текст |
| M3 подъём строк | аниматор «BrandKit M3»: Position на высоту ×1,1 → 0 за 16 кадров; маска «BrandKit M3» по блоку, нижний край открывается за последние 7 кадров | текст |
| M4 вскрытие маской | маска «BrandKit M4» по границам слоя: вход 29 кадров, выход 28; по горизонтали и вертикали | любые с размером |
| M5 поп | Scale 0 → текущий за 13 кадров; «точки» — 11 кадров лесенкой по 4 | любые |
| M6 флип куба | Rotation X: −90° → −3,6° → 0 к текущему, ключи «Умного облака» | любые, включает 3D |
| M7 блочное проявление | над слоем — солид «BrandKit M7» с Fractal Noise (Block, контраст 400, яркость −100), Random Seed +1 каждые 8 кадров, Luma-матовый слоя | любые |
| M8 пролёт рамки | Z: −1290 → 0 за 23 кадра (выход 0 → −1266 за 26); у фигур обводка +88 → текущая за 20 кадров; Z и обводка — в долях кадра 3840 | любые, включает 3D |
| M9 мерцающая сетка | как M7, но Evolution `time*40` | любые |
| M10 дрейф | Position: петля из четырёх отрезков по 15 с с `loopOut()`, амплитуда 20, 60 или 120 px FHD; у соседних слоёв свой рисунок (три рисунка курсов) | любые |
| M11 бегущая штриховка | Offset всех повторителей: `-100 + time*0.5` | фигуры с повторителем |
| M12 поп куба логотипа | Scale и X позиции — ключи пакета от текущих, Opacity 0 → текущая | любые |
