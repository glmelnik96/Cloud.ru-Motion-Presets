# Задание: установщик для команды на Mac (панель 0.1.31, библиотека 2026.10.26.3)

**Кому:** агент Cursor на Mac пользователя и сам пользователь: диалоги macOS нажимает человек.
**От кого:** сессия Claude Code на ПК сборки (Windows), 2026-10-26. Ветка `claude/determined-cannon-eum3ei`.
**Что проверяем:** установщик, который пользователь передаёт команде. Это один архив: «Установить (Windows)», «Установить (Mac)», «Как установить.pdf», «Руководство монтажёра.pdf», папка `files`. На Windows он проверен целиком (план фазы 3, пункт 5, «Установщик для команды»). На Mac лаунчер с диалогами проверен только тестами, без диалогов.

## Правила

- **Код не чинить — описывать.** Что не так: шаг, что видно, текст из Терминала, снимок экрана.
- **Тестовые проекты** — только в `/Users/Shared/CRBK/work`, закрывать без сохранения. Проекты пользователя не открывать.
- **Push — только с разрешения пользователя.** Отчёты в репозиторий не коммитятся.

## Файлы

Архив лежит на диске пользователя (на Windows это G:, на Mac — том «No tape»), в папке `Cloud.ru BrandKit`:
- `CloudRuBrandKit-0.1.31-2026.10.26.3.zip` — около 4 ГБ;
- `….zip.sha256` — его SHA-256, по нему сверяется копия.

## Шаги

### 1. Архив как скачанный

С диска карантина нет. Поставим его сами — так macOS ведёт себя, как со скачанным файлом:
```bash
cp "/Volumes/No tape/Cloud.ru BrandKit/CloudRuBrandKit-0.1.31-2026.10.26.3.zip" ~/Downloads/
cd ~/Downloads && shasum -a 256 CloudRuBrandKit-0.1.31-2026.10.26.3.zip    # = содержимому .sha256
xattr -w com.apple.quarantine "0083;$(printf %x $(date +%s));Safari;" CloudRuBrandKit-0.1.31-2026.10.26.3.zip
xattr -l CloudRuBrandKit-0.1.31-2026.10.26.3.zip
```

### 2. Распаковка двойным щелчком

Пользователь дважды щёлкает архив в Finder: распаковывает Archive Utility. Это главный риск на Mac: архив сжат deflate, 4 ГБ. Потом:
```bash
cd ~/Downloads/CloudRuBrandKit-0.1.31-2026.10.26.3
ls -l                                   # русские имена; у «Установить (Mac).command» есть x
xattr -l "Установить (Mac).command"     # карантин перешёл на распакованное
find . -type f | wc -l                  # 1498
```
Если Archive Utility не справился — запишите его сообщение и распакуйте `ditto -x -k <архив> <папка>`.

### 3. Двойной щелчок по «Установить (Mac)»

AE, Premiere и Media Encoder закрыты. Ожидаемо macOS откажет: скрипт без подписи Apple, файл в карантине. Запишите текст отказа: «Как установить» обещает, что тогда помогает Терминал.

### 4. Установка через Терминал — как в «Как установить»

Пользователь в Терминале набирает `bash` и пробел, перетаскивает в окно «Установить (Mac)» и нажимает Return. Дальше:
- первый диалог — версия и «закройте программы» → «Продолжить»;
- список отметок: 4K, музыка, пресеты AME — все отмечены → «Установить»;
- ход установки идёт в Терминале; в конце — диалог «Готово» с кнопками «Шаблоны экспорта AE», «Руководство», «Готово».

Нажмите «Шаблоны экспорта AE»: Finder должен показать `AME_Templates_aom_v1.aom`. Нажмите «Руководство»: должен открыться PDF.

**Запишите** для каждого диалога: вышел ли он поверх Терминала или его пришлось искать; понятен ли текст. Код выхода — `echo $?` сразу после.

```bash

grep -o '"libraryVersion": *"[^"]*"' /Users/Shared/CloudRuBrandKit/library/library.json
```
Откройте AE и Premiere (в Premiere — пустой тестовый проект в `/Users/Shared/CRBK/work/pr/`) → Window > Extensions > Cloud.ru BrandKit. В строке статуса — «панель 0.1.31 · библиотека 2026.10.26.3».
