## Правила

Как в прошлом задании.
- Всё делаете сами, пользователя не спрашивать. На развилке выбрать по правилам, записать выбор и идти дальше. Путь, который не вышел за 3 попытки, — к запасному.
- **Код панели не чинить — описывать.** Правки стенда — отдельным коммитом с объяснением.
- Файлы бренда (`.prtextstyle`, `.prfpset`, `.epr`, `.aom`, сборка, ZXP) в git не кладутся.
- Пароль сертификата — только через переменную окружения `BRANDKIT_CERT_PASSWORD`: не в командной строке, не в выводе, не в файлах.
- DaVinci Resolve и прочие программы пользователя не трогать. Перезапуск Premiere — по разделу «Перезапуск Premiere» прошлого задания (`2026-10-06-phase3-premiere-transfer-handoff.md`).

## 2. «Монтаж» в настоящей панели, на настоящей записи

Через интерфейс настоящей панели BrandKit (не Dev) — кликами, как монтажёр.

1. **Подготовка.** Новый scratch-проект `C:/CRBK/work/materials/premiere/edit/edit_1080.prproj`, последовательность 1920×1080 25 fps.
   - На V1 и A1 — клип со звуком: любая запись с речью или музыкой. Если в рабочих копиях пакетов нет видео со звуком, соберите 30 с через ffmpeg: `testsrc2` и `sine`.
   - У звукового клипа на A1 поставьте громкость −6 dB: через Effect Controls или скрипт, свойство Level компонента Volume.
2. **Размытие.** Выделите клип на V1, вкладка «Монтаж» → «Размыть поля выделенного клипа». Проверьте и запишите:
   - текст «готово» панели;
   - V2: копия того же времени, Crop 2,734/4,722 %; на V1 — Fast Blur 20 и Repeat Edge Pixels;
   - **звук** — главное, что не проверить на шахматке:
     - на A1 остался исходный звук с −6 dB, связь с видео V1 цела;
     - лишнего звука нет ни на A1, ни на A2.
     - Если копия перезаписала исходный звук на A1, это ошибка панели: опишите, на какую дорожку Premiere кладёт звук копии.
   - кадр через `exportFramePNG` против `docs/research/premiere/blur-mask.png` вашей прошлой проверки (если источник тот же) или просто: центр резкий, поля размыты.
3. **Отказы:**
   - повторное нажатие → «уже размыты»;
   - Ctrl+Z до исходного состояния, на V2 поставьте любой клип поверх части времени → «нужна свободная видеодорожка V2», ничего не изменилось;
   - на клипе Lumetri Color → после размытия предупреждение с его именем.
4. **4K.** Последовательность 3840×2160, тот же клип в Scale 200 → Fast Blur 38, Crop те же проценты, кадр как в 3.1 прошлого задания.

   - Создайте дорожку субтитров из `probe.srt`.

     - повторное нажатие → «уже есть в проекте», второго элемента нет.
   - **Важно:** файл в библиотеке называется `CRS_SubtitleStyle_style_v1.prtextstyle`. Запишите, под каким именем Premiere показывает его в Track Style: по имени файла, по `<Name>` внутри или по имени элемента после переименования панелью.
