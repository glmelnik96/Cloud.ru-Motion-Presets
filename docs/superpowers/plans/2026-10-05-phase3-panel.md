## Решения фазы 3 (подписаны пользователем 2026-10-05)

Подписано 2026-10-05: зависимости `typescript` и `preact` можно скачивать и ставить; P2 — «нижняя свободная, начиная с V2»; P1, P3–P10 — «по решениям согласен с тобой».


| # | Решение | Почему так |
|---|---|---|
| P1 | Вариант по кадру: точный размер; иначе той же пропорции — наименьший, что покрывает кадр (уменьшение без потери резкости), иначе ближайшая пропорция. Неточный вариант вставляется только после согласия и вписывается в кадр масштабом | spec §4.3 «плагин предлагает ближайший»; MOGRT из AE не подстраивается под секвенцию |
| P2 | Premiere: MOGRT ставится на нижнюю свободную дорожку начиная с V2 (V1 оставлена под запись); свободна она должна быть на большей из длин вставки и MOGRT по умолчанию; нет свободной — новая дорожка сверху через QE | spec §6.1 шаг 3; S5: `importMGT` только перезаписывает |
| P3 | `duration.maxSec` у `trim`-шаблонов — длина композиции; правило `trim-length` в `validate.mjs`, контракт C23 | без неё Premiere не знает, на какой длине MOGRT ляжет до обрезки |
| P4 | Эталон цвета для предупреждения в AE: рабочее пространство «нет» или Rec.709 Gamma 2.4, без линеаризации, управление цветом Adobe; 32 бита тоже предупреждение | `masters/README.md` (настройки сборки), S3: линеаризация сдвигает фото в слотах |
| P5 | Windows: папка проекта не длиннее 140 символов (из 260 оставлено 120 на «Motion Graphics Template Media» и путь капсулы) | spec §6.1 «длиннее 260 символов — Motion Graphics Template is corrupt» |
| P6 | Лог: файлы по дням, старше 7 дней удаляются, всего не больше 5 МБ; день, превысивший 1 МБ, продолжается в `.1`, `.2` | spec §8.2 «ротация 7 дней или 5 МБ» |
| P7 | Минимальная длина вставки — вход + уход + 1 кадр; меньше — отказ «не помещаются вход и уход» | иначе ключи time remap (C27) совпадают |
| P8 | Запоминаются значения полей формы, но не пути к медиа; запоминание — только после успешной вставки | медиа принадлежат проекту; неудачная вставка не должна менять форму |
| P9 | DevTools dev-установки панели: 8095 (AE), 8097 (Premiere) | рядом с 8094/8096 dev-панели, вне занятых 8088, 8092, 8098–8100 (spec §8.3) |
| P10 | Версия плагина — `panel/package.json` (сейчас 0.1.0); из неё манифест, пакет хоста и строка состояния | spec §8.1 «плагин semver» |
