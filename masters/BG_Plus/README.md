# BG_Plus — «Фон: плюсы»

Мерцающая сетка плюсов SMM-пакета («BG_pattern_9x16_2», «BG_pattern_1x1_2»): плитка «+» по всему кадру, белая на 35 %, каждый плюс то проступает, то гаснет. Это T2-петля на прозрачном (spec §5): PNG в MOV с альфой, 9 с; подложку #222222 под неё ставит панель.

Мастер `CR_BG_Plus` — только её источник: файлы рендерит `node tools/masters/render-files.mjs --item BG_Plus` из упакованного проекта (`package.mjs --only variants`).

## Как устроено

- Плитка «+» перенесена из пакета как есть (`spec.transplant`) и размножена эффектом CC RepeTile, как в пакете: от (9; 12), 50 %, шаг 75 px.
- Мерцание — яркостная маска из блочного Fractal Noise с числами пакета: масштаб 111,7, смещение, сложность 1.
- **Скорость по канону M9** (D19, подписано: 40° в секунду; в SMM-фонах пакета было 50).
- Эволюция зациклена (Cycle Evolution, один оборот): петля 9 с без шва. Узор шума поэтому другой, чем в пакете, но плотность та же: по центрам плюсов яркость 0 / 28 / 45 / 62 / 88 (мин., квартили, макс.) против 0 / 26 / 45 / 63 / 88 у пакета.

## Форматы

| Формат | Как |
|---|---|
| 9:16 | как в пакете: шаг 75 px, маска 100 % |
| 1:1 | квадрат пакета 1440 × 0,75: шаг 56 px, маска 50 % (как в пакете) |
| 16:9 | как 9:16 (тот же размер плюсов в FHD) |

## Сверка (`node tools/masters/compare.mjs --item BG_Plus`)

Сетка совпадает с пакетом, яркости плюсов — нет (другой узор шума): только просмотр, SSIM 0,98.
