# BG_WebinarPortal — «Фон экрана вебинара»

Фон четырёх экранов вебинаров («Заставка/Таймер с вижуалом/со спикером»):
- тёмная земля #222222;
- мятный «портал» из двух плашек: правый край левой плашки медленно ездит;
- сетка стрелок «стеллаж» на плашках: неподвижная полоса в экранах с визуалом, мерцающая сетка в экранах со спикером;
- две сетки точек на заставке со спикером.

Это T2-петля, непрозрачная (spec §5: компаньон T1 «Экран вебинара», который кладёт поверх заголовки, логоблок, слоты визуала и спикера, QR и таймер): PNG в MOV, 60 с, 16:9.

Мастер `CR_BG_WebinarPortal` — только её источник: файлы рендерит `node tools/masters/render-files.mjs --item BG_WebinarPortal` из упакованного проекта (`package.mjs --only variants`).

## Поля (форма панели)

| Поле | Что делает |
|---|---|
| Раскладка | С визуалом / Со спикером — выбирает файл |
| С таймером | Фон экрана с таймером: у визуала полоса стрелок уже и правее (слева место под таймер), у спикера нет точек |

## Как устроено

- Фоновые слои каждого из четырёх экранов перенесены как есть (`spec.transplant`), по композиции на экран. Слои шаблона (тексты, логоблок, слоты, QR, таймер, плашки спикера) не взяты: их положит «Экран вебинара».
- **Портал по канону M10** (D19, подписано: «портал вебинаров — на общую кривую»). Край проходит четыре точки разворота пакета (118 → 417,41 → 229,21 → 402,44 px от середины кадра), по 15 с на отрезок на кривой `0.775,0,0.667,1`. Петля 60 с без шва. Ключи маски пакета заменены выражением на пути маски.
  - В пакете отрезки шли 15–21 с с другими кривыми (таймер, цикл 75 с), а заставка за свои 30 с проходила только часть пути.
  - Ручные ключи пакета смещали углы края на 0,08–0,24 px — мастер держит их на месте.
- **Мерцание «стеллажа»** (экраны со спикером) зациклено, чтобы совпасть с петлёй 60 с: 7 оборотов эволюции, 42°/с. Канон M9 — 40°/с, но при 40 петля кончилась бы на 2/3 оборота, со швом.
- Мятный — #8EE7BB, как в пакете. В D1 он пока «на сопоставлении с брендбуком» (`tokens.json` → `color.pending`).

## Сверка (`node tools/masters/compare.mjs --item BG_WebinarPortal`, 2026-10-23)

По частям кадра без слоёв шаблона, на 0 с (край портала там же, где у пакета):
- земля под логоблоком, между плашкой и QR, справа от правой плашки — 1,0000;
- полоса стрелок у визуала — 1,0000 (с таймером — 0,9837);
- точки заставки со спикером — 0,9996.

Мерцание «стеллажа» — на глаз (другой узор шума из-за цикла).
