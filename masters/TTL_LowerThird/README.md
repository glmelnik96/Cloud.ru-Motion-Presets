# TTL_LowerThird — «Подпись спикера»

Мастер `CR_TTL_LowerThird`: 1920×1080, 25 fps, 6,00 с, плоский, motion blur выключен. Варианты: `16x9`, `16x9_4K`, `9x16`, `1x1`.

Три стиля, переключаются списком «Стиль» (D15):

| Стиль | Источник | Как выглядит |
|---|---|---|
| 1 «Титры» | Titles, «Подпись_спикеров» | Две плашки #222222 с белой кромкой; имя и должность (до двух строк) — SB Sans Text Regular 50 / 37,5 px, белым |
| 2 «Подкаст» | подкаст, «Подпись_спикера_1» и «_2» | Одна плашка #F2F2F2 в углу окна рамки подкаста; должность прописными над именем; имя — SB Sans Display Bold 90 px прописными, справа; две стрелки |
| 3 «Вебинар» | вебинары, «Заставка со спикером» | По плашке #222222 на строку: «Имя,», должность, вторая строка; SB Sans Display Regular 35 px, трекинг 19, белым |

Мастер строится из декларативного описания: Node пишет слои, ключи, выражения и матте, общий сборщик `tools/masters/jsx/build-spec.jsx` их создаёт. Файлы стилей: `style-titles.mjs`, `style-podcast.mjs`, `style-webinar.mjs`.

## Поля

| Поле | Слой / контрол | Что делает |
|---|---|---|
| Имя | TXT_NAME | Общие поля для всех стилей. В «Титрах» эти слои показываются сами, в других стилях их текст берут слои стиля (POD_*, WEB_*) |
| Должность | TXT_ROLE1 | — |
| Должность, 2-я строка | TXT_ROLE2 | — |
| Стиль | Список на CTRL | Титры / Подкаст / Вебинар |
| Сторона | Список на CTRL | Слева / Справа. В «Подкасте» «Справа» — ведущий («_1»), «Слева» — гость («_2»), зеркально |

Шрифт каждого стиля закреплён за его слоями — шрифт выражением не меняется. MOGRT несёт все четыре шрифта: SB Sans Text Regular; SB Sans Display Bold, Semibold и Regular.

Пустая строка должности убирает свою строку или плашку: в «Титрах» и «Подкасте» плашка становится ниже на строку, в «Вебинаре» исчезает плашка этой строки. В «Подкасте» без должности нет и стрелок.

## Время

- 6,00 с. Защищённые области: in 0–1,64 с (самое длинное интро — строки должности в «Титрах»), out 4,52–6,00 с (самый длинный выход — «Подкаст», 1,48 с).
- «Титры»: интро 0–1,64 с как в пакете; выход 4,88–5,96 с (у пакета 4,40–5,48 с).
- «Подкаст»: в пакете плашка стартует в 0,60 с, после пролёта рамки; здесь — в 0 с. Слова поднимаются до 1,48 с. Выход 4,52–6,00 с (у пакета 7,88–9,36 с).
- «Вебинар»: в пакете подпись неподвижна. Здесь движение «Титров» построчно с шагом 0,24 с: плашки с кромкой растут, слова поднимаются на 1,125 кегля. Выход в обратном порядке: последняя строка первой.

## Решения по умолчанию (не подписаны)

| Решение | Принято сейчас |
|---|---|
| Масштаб «Титров» | Холст пакета 1500×500 считается UHD: в FHD имя 50 px. Если холст ставили в FHD на 100 %, всё нужно удвоить |
| D4 — выход «Титров» | Как в оригинале: схлопывание к дальнему краю, должность на 0,24 с раньше имени, кромки отстают на кадр |
| D1 — цвет «Подкаста» | Плашка #F2F2F2 вместо #D3D3D3 пакета |
| D15 — Bold в «Подкасте» | Имя — SB Sans Display Bold, как в пакете (в брендбуке у Display только Regular и Semibold — вопрос к бренду) |
| «Подкаст», место | Угол окна рамки подкаста: 52,5 px от края кадра и 51 px от низа (FHD). Гость — зеркально, анимация ведущего для обоих (у гостя в пакете тайминг чуть другой) |
| «Вебинар», движение | Новое (в пакете его нет): семейство «Титров» построчно. Запятая после имени ставится стилем. Каждая строка стоит в своей плашке; в пакете текст шёл с шагом 47 px поверх плашек с шагом 49,25 |
| Место «Титров» и «Вебинара» | 100 px от бокового края. Низ самого высокого блока — в 100 px от низа кадра; имя не прыгает при одной строке |
| Поля плашек | «Титры»: 8,33 px до текста, правое 13,5 px. «Подкаст»: имя в 22,86 px от правого края, 25,8 px слева, должность с отступом 153,6 px. «Вебинар»: 9,48 px до текста, правое 16 px. Всё — по пакету, ширины плашек подогнаны вручную. Сетка 2 px (G1) — вопрос к дизайнеру |

## Сверка с эталоном (`node tools/masters/compare.mjs --item TTL_LowerThird`)

Прогон 2026-10-03:

| Стиль | Удержание (порог 0,98) | Примечание |
|---|---|---|
| «Титры», вариант 4K против холста 1500×500 | SSIM 0,9828, альфа 0,99 | Окно совмещено на (149,4; 1588,6) — где его предсказала геометрия дампа |
| «Подкаст», 4K, внутри плашки | SSIM 0,9928, альфа 1,0 | Цвет плашки эталона пересчитан по D1 (#D3D3D3 → #F2F2F2). Замаскирована «Й»: в рендере пакета она без бреве (дефект оригинала) |
| «Вебинар», FHD | только на глаз | Эталон неподвижен внутри экрана вебинара; строки 2–3 у мастера стоят по центру своих плашек |

Кадры с движением сравниваются на глаз: у эталонов motion blur, а рамка подкаста в начале летит в 3D.
