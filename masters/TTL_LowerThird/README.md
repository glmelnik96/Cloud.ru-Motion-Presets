# TTL_LowerThird — «Подпись спикера»

Мастер `CR_TTL_LowerThird`: 1920×1080, 25 fps, 6,00 с, плоский, motion blur выключен.

Сейчас собран стиль «Титры» по «Подпись_спикеров» из пакета Titles. Стили «Подкаст» и «Вебинар» (D15) — следующий шаг. Их подключит выпадающий список «Стиль».

Варианты: `16x9`, `16x9_4K`, `9x16`, `1x1`.

## Слои

| Слой | Что делает |
|---|---|
| CTRL | Выпадающий список Side («Сторона»: Слева / Справа) и флажок QA (в Essential Graphics не выводится) |
| RIG | Скрытый слой-нуль. Слайдеры NameIn, RoleIn, NameOut, RoleOut (рост и схлопывание плашек) и RoleStart (подъём строк должности) с ключами пакета |
| QA_PATCH | Квадрат #26D07C для проверки цвета ΔE |
| EDGE_NAME, EDGE_ROLE | Белые кромки. На входе опережают плашку на кадр, на выходе отстают на кадр |
| TXT_NAME | Имя: SB Sans Text Regular 50 px, белый. Слова поднимаются на 56,25 px (аниматор, по словам) |
| TXT_ROLE1, TXT_ROLE2 | Строки должности: 37,5 px, шаг 43,75. Подъём на 91,4 px; каждая строка в своём окне кривой пакета |
| PL_NAME, PL_ROLE | Плашки #222222. Видимы и одновременно служат альфа-матте для текста |

Ширина плашки = 8,33 px до начала текста + ink самой длинной строки + 13,5 px, с округлением до целых пикселей мастера.

Пустая вторая строка даёт плашку на одну строку. Если пуста первая, вторая встаёт на её место. Если пусты обе, плашки должности нет (C11).

## Решения по умолчанию (не подписаны; ждут пользователя и дизайнера)

| Решение | Принято сейчас | Откуда |
|---|---|---|
| Масштаб «Титров» | Холст пакета 1500×500 считается UHD: в FHD имя 50 px, должность 37,5 px, зазор плашек 5 px | разбор пакета. Если холст ставили в FHD на 100 %, всё нужно удвоить |
| D4 — выход | Как в оригинале: плашки схлопываются к дальнему краю, должность на 0,24 с раньше имени, кромки отстают на кадр | дамп «Подпись_спикеров» |
| Сторона «Справа» | Зеркало по горизонтали: плашки прижаты к правому полю, растут справа налево; текст внутри плашек выровнен влево | предложение разбора |
| Место в кадре | 100 px от бокового края. Низ самого высокого блока (две строки должности) — в 100 px от низа кадра; имя не прыгает при одной строке | предложение разбора, утверждает дизайнер |
| Длительность | 6,00 с. Интро 0–1,64 с, удержание 1,64–4,88 с, выход 4,88–5,96 с (у пакета 4,40–5,48 с). Защищённые области in 0–1,64 и out 4,88–6,00 | дамп пакета |
| Поля плашек | Как в пакете: 8,33 px до текста, правое поле 13,5 px (пакет: 13,2 у имени и 13,8 у должности; подогнаны вручную) | дамп, замер текста в AE (`source-metrics.json`) |
| Шрифт | SB Sans Text Regular (D15 для «Титров») | дамп |

## Сверка с эталоном (`node tools/masters/compare.mjs --item TTL_LowerThird`)

Прогон 2026-10-03. Вариант 16x9_4K с текстами пакета против холста «Подпись_спикеров» 1500×500. Окно совмещено с субпиксельной точностью на (149,4; 1588,6); геометрия дампа предсказала (149,42; 1588,57).

| Кадры | Итог |
|---|---|
| Удержание t2000, t3000, t4000 (порог 0,98) | SSIM 0,9828, альфа 0,99 — проходит |
| Интро и выход (на глаз) | 0,89–0,98. Разница — motion blur эталона: белая кромка у мастера резкая (C35) |

## Premiere (`node tools/masters/pr-check.mjs --item TTL_LowerThird`)

Прогон 2026-10-03, Premiere 26.5.2, `TTL_LowerThird_16x9_v1.mogrt`:
- клип A: тексты пакета, слева, длина по умолчанию 6 с;
- клип B: справа, «Анна-Мария Ёлкина-Константинопольская», одна строка должности, длина 10 с;
- поля пишутся и читаются в новом вызове, кириллица и «Ё» целы;
- кадры против AE: SSIM 0,995–0,998, включая интро и выход растянутого клипа.
