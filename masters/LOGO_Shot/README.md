# LOGO_Shot — «Логошот с подписью»

Мастер `CR_LOGO_Shot`: 1920×1080, 25 fps, 5,00 с, Classic 3D, motion blur выключен, плоский. Варианты: `16x9`, `16x9_4K`, `9x16`. Когда кадр выше, чем шире, раскладка переключается на «стопку» по «Логошоты вертикальный_Умное облако».

Заменяет:
- «Логошот_Умное облако» и «Логошот_Есть где развернуться» (пакеты logo и logo_conv);
- копию логошота в подкасте.

Канон движения и геометрии — прекомп «Умное облако»: кривые там выверены, «Есть где развернуться» — поздняя копия.

## Слои

| Слой | Что делает |
|---|---|
| CTRL | Выпадающие списки Caption («Подпись»), Theme («Тема»), Background («Фон») и флажок QA (в Essential Graphics не выводится) |
| RIG | Скрытый слой-нуль. Слайдеры прогресса с ключами и кривыми пакета: для 16:9 — Open, Slide, Unroll, CloseW, CloseX; для 9:16 — VOpen, VRise, VGrow, VClose |
| CAMERA | Камера 50 мм по умолчанию, заданная явно; следует за размером кадра |
| QA_PATCH | Квадрат #26D07C для проверки цвета ΔE |
| CAPTION | Живой текст SB Sans Display Semibold 40 px в одну строку (16:9). Текст берётся из списка, цвет — из темы (эффект Fill) |
| CAPTION_V | То же для 9:16: по центру, трекинг 8, интерлиньяж 40,82, с переносами строк |
| LOCKUP | Логотип из мастера SVG (D18) в масштабе 2/3 (знак 39,68 px). 3D-переворот по X с ключами пакета |
| PL_CAPTION, PL_LOGO | Плашки. Видимы и одновременно служат альфа-матте для подписи и логотипа |
| BG | Подложка: прозрачная, #222222 или #F2F2F2 |

Геометрия считается выражениями от k = min(w, h) / 1080. Поэтому вариант — это копия мастера с другим размером кадра и кеглем × k.

| 9:16 — подписи | «облачные⏎и ИИ-сервисы» (как в пакете), «умное облако» (одна строка, плашка ниже на строку), «есть где⏎развернуться» (новый перенос) | D5, утверждает дизайнер |

## Сверка с эталоном (`node tools/masters/compare.mjs --item LOGO_Shot`)

Последний прогон — 2026-10-03, вариант 16x9_4K против 4K-эталонов пакета logo:

| Кейс | Кадры удержания (порог SSIM 0,98) | Кадры с движением (на глаз) |
|---|---|---|
| «есть где развернуться», светлая тема, прозрачный фон | t2760, t3000: SSIM 0,9926, альфа 1,0000 — проходит | переворот 0,97–0,99. Сдвиг и аутро ниже: у этой копии в пакете свой тайминг (сдвиг до 2,40 с), а мастер идёт по «Умному облаку» |
| «облачные и ИИ-сервисы», фон #F2F2F2 | порога нет: в 2,14–3,30 с у эталона пропадают ~25 px плашки (квирк рендера оригинала в обоих пакетах) | 0,93–0,996; разница — motion blur эталона (C35 его выключает) |
| 9:16 «облачные⏎и ИИ-сервисы», тёмная тема | t2760, t3000: SSIM 0,9827, альфа 0,9827 — проходит. Кадр совмещён на (4; 4,4). Логотип замаскирован: по D18 он из мастера SVG, а в вертикальной копии пакета надпись W3 на 1,2 % шире (сверено на глаз) | 0,52–0,94: тайминг подъёма и схлопывания сведён к 16:9, у эталона motion blur |

## Premiere (`node tools/masters/pr-check.mjs --item LOGO_Shot`)

Прогон 2026-10-03, Premiere 26.5.2, `LOGO_Shot_16x9_v1.mogrt` в секвенции 1080p25:
- вставка и длина по умолчанию 5 с — работают;
- клип B растянут до 8 с: интро, удержание и аутро идут со скоростью мастера;
- поля «Подпись», «Тема», «Фон» пишутся (индексы с 0) и читаются в новом вызове;
- кадры против рендера AE: SSIM 1,0000 (удержание, интро, аутро), 0,9962 (переворот), ΔE зелёного 0,00.
- 9:16 (`--plan premiere9x16`): секвенция 1080×1920 25p из пресета 1080p25 через `setSettings`; клип 7 с, «есть где⏎развернуться», тёмная тема. SSIM 0,995–0,999, ΔE 0,00.
