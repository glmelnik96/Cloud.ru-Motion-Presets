# Мастера шаблонов (фаза 1)

Каждый мастер — папка `masters/<id>/`:

| Файл | Что делает |
|---|---|
| `resolve.mjs` | Node: числа из JSX-дампов пакета, логотип из мастера SVG (D18), цвета и тексты из `brand/tokens.json` → параметры сборки. Числа не перепечатываются руками. |
| `build.jsx` | AE (ES3): новый проект, мастер-композиция, Essential Graphics, сохранение `<work>/build/<id>/<id>_work.aep` |
| `ref.json` | Сверка с эталонными кадрами пакета: кейсы, моменты, какие кадры — порог SSIM, какие — «на глаз» |
| `README.md` | Решения, принятые по умолчанию до подписей пользователя, и итоги сверки |

Конвейер (по одному вызову AE на шаг, AE запускается заранее, открытый проект пользователя не трогается):

```bash
node tools/masters/build-master.mjs --item LOGO_Shot
node tools/masters/package.mjs --item LOGO_Shot
node tools/masters/compare.mjs --item LOGO_Shot
node tools/masters/pr-check.mjs --item LOGO_Shot
```

- `build-master` собирает мастер.
- `package` делает варианты форматов (`comp.duplicate()` с новым размером; кегль × k, k = min(w, h) / 1080) и экспортирует `.mogrt`, по одному на вызов.
- `compare` рендерит варианты с полями кейса и сравнивает с эталонами: SSIM по яркости поверх чёрного и белого плюс альфа. Для глаза пишет картинки «эталон | мастер | разница».
- `pr-check` вставляет MOGRT в тестовый `C:/CRBK/work/pr/CRT_masters.prproj`, пишет поля (в Premiere индексы списков с 0) и читает их в новом вызове. Кадры Premiere сравниваются с рендером AE того же варианта: SSIM и ΔE фирменного зелёного.

Выходы лежат в `C:/CRBK/work/build/<id>/`: рабочий и упакованный `.aep`, `mogrt/`, `ref/<кейс>/`, отчёты `*-report.json`.

Квирки AE 26.5, найденные при сборке (2026-10-03):
- Новый проект AE наследует цветовые настройки последнего проекта: линеаризованное sRGB из S3 попало в мастер. MOGRT уносит их в Premiere, и там цвет становится v^(1/2,4): #222222 → #6E6E6E. Сборщик ставит 8 бит, «без рабочего пространства» и без линеаризации. Присвоение 'None' вызывает модальное предупреждение, поэтому оно идёт с подавлением диалогов и только при необходимости.
- `setTrackMatte` выключает видимость слоя-матте, как в интерфейсе. Плашки логошота — и матте, и видимые слои, поэтому их включают обратно.
- Выражение, которое ссылается на ещё не созданный слой, AE сразу выключает. Поэтому выражения ставятся последним шагом, и проверяется `expressionEnabled`.
- Композиция, у которой размер изменён скриптом, сохраняет камеру по умолчанию от старого размера. 3D-слои съезжают на половину разницы размеров (в 4K-варианте логотип уехал за матте). В мастерах с 3D-слоями нужна явная камера 50 мм, привязанная к `thisComp.width/height`.
