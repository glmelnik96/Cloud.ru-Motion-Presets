# BG_Arrows — «Фон: стрелки»

Фон со стрелками SMM-пакета («BG_pattern_9x16_1», «BG_pattern_1x1_1»): сетка из 390 белых стрелок на 25 %, видны только те, что ближе 2000 px (в 4K) к точке, которая медленно бродит по кадру. Это T2-петля на прозрачном (spec §5): PNG в MOV с альфой, 15 с; подложку #222222 под неё ставит панель.

Мастер `CR_BG_Arrows` — только её источник: файлы рендерит `node tools/masters/render-files.mjs --item BG_Arrows` из упакованного проекта (`package.mjs --only variants`).

## Как устроено

- 4K-композиция пакета «PATTERN_EDIT» перенесена как есть (`spec.transplant`): 390 плиток со своими выражениями размера, точка `Null 1`, настройки.
- **Петля.** В пакете точка бродит по `wiggle(0.3, 1000)`, а он не повторяется: 30-секундный рендер пакета не бесшовный. В мастере тот же `wiggle` смешан сам с собой со сдвигом на период, и петля длится 15 с без шва. Кадр 0 тот же, что в пакете.

## Форматы

| Формат | Как |
|---|---|
| 9:16 | как в пакете: 125 % от (570; 933), со свёрткой (линии остаются чёткими) |
| 1:1 | квадрат пакета 1440 × 0,75: 75 % от (517,5; 562,5) |
| 16:9 | в пакете нет: 4K-композиция целиком, 50 % |

## Сверка (`node tools/masters/compare.mjs --item BG_Arrows`, 2026-10-23)

- кадр 0 в 9:16 — 1,0000, в 1:1 — 0,9986;
- дальше точка идёт по петле, а не по пакету (5 с — 0,92, только просмотр);
- порядок кадров — 1,0.

## Решения по умолчанию (не подписаны)

| Решение | Принято сейчас |
|---|---|
| Петля | 15 с (из матрицы T2), `wiggle` смешан сам с собой |
| 16:9 | Вся 4K-композиция, как её нарисовал пакет (стрелки 75 px в FHD — мельче, чем в 9:16) |
| 4K | Петля 16:9 4K (`16x9_4K`) — опция «4K-фоны и клипы» установщика (D24). Без неё в 4K-секвенции панель берёт FHD-петлю, вписанную в кадр |
