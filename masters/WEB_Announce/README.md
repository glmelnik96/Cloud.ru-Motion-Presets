# WEB_Announce — «Анонс вебинара»

Мастер `CR_WEB_Announce`: 25 fps, композиция 60 с (`trim`), motion blur выключен. Варианты `1x1` (1080×1080) и `9x16` (1080×1920).

Два поста пакета вебинаров — «Анонс_Вебинар_1x1» (1400×1400) и «Анонс_Вебинар_9x16» — один шаблон. Раскладку выбирает кадр: квадрат или вертикаль.

## Поля

| Поле | Слой | Что делает |
|---|---|---|
| Заголовок, строка 1–3 | TXT_TITLE1–3 | Строки заголовка; пустые пропускаются, следующие поднимаются. Длинная строка уменьшает весь блок |
| Дата | TXT_DATE | Строка «Вебинар ↗ <дата> ↗». Без даты остаётся «Вебинар ↗». Длинная дата уменьшает строку до её места |
| Визуал | SLOT_VISUAL | Слот Media Replacement (видео или фото) размером с визуал пакета, 1976×1580: подставленное медиа заполняет его. Квадрат режет его карточкой с вырезами, вертикаль — окном. По умолчанию — светлая карточка #ECECEC (D13) |

## Как устроено

- Раскладку выбирает кадр (`thisComp.height < thisComp.width × 1,3` — квадрат). Варианты — копии одной композиции.
- Заголовок — одни и те же слои в обеих раскладках. Цвет и трекинг даёт аниматор «Ink» выражением, кегль — масштаб слоя.
  - Tracking Amount аниматора — пиксели на знак при кегле слоя, а не тысячные эма: трекинг 16 при 70 px — это 1,12 (AE 26.5).
- Стрелки — обводка пакета: 4,32 px при его 1400, стыки и концы по умолчанию AE.
