# LOGO_Mark — «Логотип без подписи»

Мастер `CR_LOGO_Mark`: 1920×1080, 25 fps, 4,00 с, плоский, без 3D, motion blur выключен. Варианты: `16x9`, `16x9_4K`, `9x16`. В 9:16 логотип ×1,35, как в обёртках пакета.

Заменяет «Логошот без саблайна», «…с плашкой» и их обёртки 9:16.

Движение M12 «как есть»:
- куб появляется в центре кадра (прозрачность 0→100, масштаб 250→350 %) за 0–1,00 с;
- затем уменьшается и уходит влево, а надпись выезжает из-за него — стирание по инвертированному матте;
- с подложкой она растёт от куба.

## Слои

| Слой | Что делает |
|---|---|
| CTRL | Флажок Plate («Подложка», по умолчанию вкл.), списки Theme («Тема»: Светлая / Тёмная, по умолчанию тёмная, как в пакете) и Background («Фон»), флажок QA (в Essential Graphics не выводится) |
| RIG | Скрытый слой-нуль. Кривые пакета в реальных значениях: набор A (без подложки) — X_A, S_A, O_A, W_A; набор B (с подложкой) — X_B, S_B, O_B, W_B, P_B; аутро — WipeBack, Collapse |
| WORDMARK, WIPE | Надпись из мастера SVG и прямоугольник, который её прячет (инвертированное альфа-матте, сам скрыт) |
| CUBE | Знак из мастера SVG |
| PLATE | Подложка: растёт от куба; в теме «Тёмная» #222222, в «Светлой» #FFFFFF |
| BG, QA_PATCH | Фон и патч проверки цвета, как у LOGO_Shot |

Оба оригинала анимированы по-разному: средний ключ на 1,75 с против 1,626 с, разные кривые. Поэтому флажок «Подложка» выбирает свой набор кривых, и каждый режим повторяет свой оригинал.

## Решения по умолчанию (не подписаны)

| Решение | Принято сейчас |
|---|---|
| Аутро | В пакете его нет. Без подложки (временное): 3,40–3,76 с надпись уезжает за куб, 3,60–3,96 с куб схлопывается в свой центр. С подложкой (по замечанию пользователя 2026-10-05): 3,40–3,96 с подложка схлопывается к центру и срезает логотип по маске, без отдельного масштаба |
| Цвет надписи | #F7F7F7 пакета → #FFFFFF (D1) |
| Ключи | Сняты на сетку кадров: 1,75 → 1,76 с, 1,626 → 1,64 с; скорости пересчитаны |
| Положение | Как в пакете: в покое центр логотипа на 4,4 px правее центра кадра, куб на 0–1 с — точно в центре |
| Защищённые области | in 0–2,96 с, out 3,20–4,00 с — рассчитаны на скорость 0,75× (контракт C44) |

## Сверка с эталоном (`node tools/masters/compare.mjs --item LOGO_Mark`)

Прогон 2026-10-03, вариант 9x16 против обёрток 9:16 пакета (эталона 16:9 у этих композиций нет):

| Кейс | Удержание (порог 0,98) | Движение (на глаз) |
|---|---|---|
| без подложки | t2520, t2760: SSIM 0,9971, альфа 0,9999 | 0–1,00 с: 0,9995; середина 0,73–0,96 — motion blur эталона |
| с подложкой | t2520, t2760: SSIM 0,9998, альфа 1,0000 | 0–1,00 с: 0,9993; середина 0,78–0,98 |

Геометрия покоя совпадает с дампом до сотых пикселя: куб 60,77×63,76 в (782,03; 509,37), подложка 438,38×127,34 в (742,48; 475,90).

## Premiere (`node tools/masters/pr-check.mjs --item LOGO_Mark`)

Прогон 2026-10-05, `LOGO_Mark_16x9_v1.mogrt` (4 с, со «Скоростью»):
- клип A: с подложкой, тёмная тема, тёмный фон, длина по умолчанию; кадр 3,68 с — подложка срезает логотип;
- клип B: без подложки, светлая тема, светлый фон, длина 6 с;
- клип C: с подложкой, скорость 0,75×, длина 6 с;
- флажок и списки пишутся и читаются;
- кадры против AE: A и B — SSIM 1,0000, ΔE зелёного 0,00, в том числе аутро растянутого клипа; C — SSIM 0,9940 и 0,9980, ΔE 0,74.

На 0,75× время мастера дробное (0,9 с — это 22,5 кадра). На таких кадрах Premiere и AE расходятся на доли пикселя по краю куба. Поэтому цвет меряется на сплошном участке 12×12: центр тяжести куба падает на зазор между гранями, и там меряется сглаживание края, а не цвет (`findSolidPatch`). Первый прогон 2026-10-03 (без «Скорости») — SSIM 1,0000.
