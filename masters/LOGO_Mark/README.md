# LOGO_Mark — «Логотип без подписи»

Мастер `CR_LOGO_Mark`: 1920×1080, 25 fps, 3,60 с, плоский, без 3D, motion blur выключен. Варианты: `16x9`, `16x9_4K`, `9x16`. В 9:16 логотип ×1,35, как в обёртках пакета.

Заменяет «Логошот без саблайна», «…с плашкой» и их обёртки 9:16.

Движение M12 «как есть»:
- куб появляется в центре кадра (прозрачность 0→100, масштаб 250→350 %) за 0–1,00 с;
- затем уменьшается и уходит влево, а надпись выезжает из-за него — стирание по инвертированному матте;
- с подложкой она растёт от куба.

## Слои

| Слой | Что делает |
|---|---|
| CTRL | Флажок Plate («Подложка», по умолчанию вкл.), списки Theme («Тема»: Светлая / Тёмная, по умолчанию тёмная, как в пакете) и Background («Фон»), флажок QA (в Essential Graphics не выводится) |
| RIG | Скрытый слой-нуль. Кривые пакета в реальных значениях: набор A (без подложки) — X_A, S_A, O_A, W_A; набор B (с подложкой) — X_B, S_B, O_B, W_B, P_B; аутро — WipeBack, Collapse |
| WORDMARK, WIPE | Надпись из мастера SVG и прямоугольник, который её прячет (инвертированное альфа-матте, сам скрыт) |
| CUBE | Знак из мастера SVG |
| PLATE | Подложка: растёт от куба; в теме «Тёмная» #222222, в «Светлой» #FFFFFF |
| BG, QA_PATCH | Фон и патч проверки цвета, как у LOGO_Shot |

Оба оригинала анимированы по-разному: средний ключ на 1,75 с против 1,626 с, разные кривые. Поэтому флажок «Подложка» выбирает свой набор кривых, и каждый режим повторяет свой оригинал.

## Решения по умолчанию (не подписаны)

| Решение | Принято сейчас |
|---|---|
| Аутро | В пакете его нет: маркер «схлопнуть в точку» стоит за концом композиции. Временный вариант: 3,00–3,36 с надпись уезжает обратно за куб, подложка сворачивается; 3,20–3,56 с куб схлопывается в свой центр. Длина 3,60 с. Утверждает или перерисовывает дизайнер |
| Цвет надписи | #F7F7F7 пакета → #FFFFFF (D1) |
| Ключи | Сняты на сетку кадров: 1,75 → 1,76 с, 1,626 → 1,64 с; скорости пересчитаны |
| Положение | Как в пакете: в покое центр логотипа на 4,4 px правее центра кадра, куб на 0–1 с — точно в центре |
| Защищённые области | in 0–2,20 с, out 3,00–3,60 с |
