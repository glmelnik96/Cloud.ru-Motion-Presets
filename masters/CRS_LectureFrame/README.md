# CRS_LectureFrame — «Рамка лекции»

Рамка трёх оверлеев лекций курсов («Оверлей 16 на 9», «3 на 2», «со спикером»; 1920×1080, в пакете по часу каждый) — не шаблон, а файлы (D9):
- **стилл** на каждую раскладку, FHD и 4K: PNG с прозрачными окнами, сквозь которые видна запись;
- **петля дрейфа** на 60 с, FHD: PNG в MOV с альфой (D24), по умолчанию выключена;
- **окна** раскладки — для «Вписать в окно» в Premiere.

Мастер `CR_CRS_LectureFrame` (1920×1080, 25 fps, 60 с) — только их источник: файлы рендерит `node tools/masters/render-files.mjs --item CRS_LectureFrame` из упакованного проекта (`package.mjs --only variants`). Запись в библиотеке строит `libraryEntry()` мастера; тест сверяет её с `library.src.json`.

## Поля (форма панели)

| Поле | Что делает |
|---|---|
| Раскладка | Экран 16:9 / Экран 3:2 / Спикер слева / Спикер справа — выбирает файл и окна |
| Дрейф | Петля 60 с вместо стилла: уголки рамки медленно ездят, как в пакете. По умолчанию выключен |

Рамка ложится над записью: экран и спикер — на дорожках ниже, «Вписать в окно» ставит их в окна.

## Раскладка (FHD)

| Раскладка | Окно экрана | Окно спикера |
|---|---|---|
| Экран 16:9 | 1600×900 в (150; 100) | — |
| Экран 3:2 | 1350×900 в (275; 100) | — |
| Спикер слева | 1248×702 в (601; 174) | 500×750 в (50; 150) |
| Спикер справа | 1248×702 в (71; 174) | 500×750 в (1370; 150) |

- Фон #222222; в раскладках со спикером — узор пакета «Pattern Arrow» и тёмная плашка под логотипом, как в пакете.
- Логотип — мастер-логотип (D18) на месте логотипа пакета.
- Зелёные уголки — шесть слоёв пакета как есть (`spec.transplant`), одинаковые во всех трёх оверлеях: ключи 0–15–30–45–60 с, цикл 60 с (`loopOut`). В раскладках экрана они лежат поверх записи, в раскладках со спикером — под ней (окна вырезают и их), как в порядке слоёв пакета.
- В 4K всё вдвое больше FHD; перенесённые слои растрируются в размере кадра («collapse»).

## Решения по умолчанию (не подписаны)

| Решение | Принято сейчас |
|---|---|
| Окно 3:2 | 1350×900 вместо маски пакета 1300×900 (13:9): запись 3:2 входит без обрезки (D9). Центр окна — центр маски пакета |
| Окно экрана со спикером | 1248×702 (16:9) вместо 1250×751 (5:3) пакета: та же ширина на сетке 16 px, по середине окна спикера. Запись 16:9 входит без обрезки (D9) |
| «Спикер справа» | Зеркало «Спикер слева» по окнам; логотип, плашка, узор и уголки не зеркалятся (в пакете только спикер слева) |
| Сторона в раскладке | Сторона спикера — пункт «Раскладки», а не отдельное поле: у раскладок экрана стороны нет |
| Субтитры | Не в рамке: отдельный элемент «Субтитры» (`CRS_Subtitles`) |
| Петля в 4K | Нет: петли только FHD (D24, 4K — отдельной опцией установщика позже). В 4K-секвенции панель предложит FHD-петлю, вписанную в кадр |
| Стилл — первый кадр цикла | Уголки на ключе 0 с; петля начинается с того же кадра |
