# SMM_FrameNotched — «Рамка с вырезами»

Рамка двух оверлеев SMM-пакета («Оверлей_9x16», «Оверлей_1x1»): шесть тёмных прямоугольников по краям кадра, на верхнем и нижнем крае — по ступеньке-вырезу, которая медленно ездит вдоль края. Это не шаблон, а файлы (spec §5: T2 и стилл):
- **стилл** на каждый формат и цвет — рамка в покое, PNG с альфой;
- **петля дрейфа** на 60 с — PNG в MOV с альфой (D24), по умолчанию выключена.

Мастер `CR_SMM_FrameNotched` (1080×1920, 25 fps, 60 с) — только их источник: файлы рендерит `node tools/masters/render-files.mjs --item SMM_FrameNotched` из упакованного проекта (`package.mjs --only variants`). Запись в библиотеке строит `libraryEntry()` мастера; тест сверяет её с `library.src.json`.

## Поля (форма панели)

| Поле | Что делает |
|---|---|
| Цвет | Зелёный (#26D07C) / Тёмный (#222222, по умолчанию, как в пакете) / Белый (#FFFFFF) — выбирает файл |
| Дрейф | Петля 60 с вместо стилла: ступеньки ездят вдоль краёв. По умолчанию выключен |

Рамка ложится над роликом. Формат файла панель берёт по кадру.

## Как устроено

- Прямоугольники собраны заново по числам дампа: размеры и положения покоя из общего квадратного рисунка пакета. Пакет раскладывает этот рисунок трансформом слоя (9:16 — сжатие 70 × 130 %, 1:1 — квадрат 1440), мастер делает так же. Сборка проверяет, что оба оверлея пакета — один рисунок.
- **Дрейф по канону M10** (D19, подписано: «вырезы SMM — на общую кривую»). Ступеньки проходят точки разворота из ключей пакета, по 15 с на отрезок, на кривой `0.775,0,0.667,1`, по одной оси за отрезок; четыре отрезка — петля 60 с без шва.
  - Верхняя ступенька ездит только по X: −367,9 → −534,5 → −163,6 → −671,9 → −367,9 (единицы рисунка).
  - Нижняя — по X, вверх на 16 px, обратно по X, вниз.
  - В пакете обе ездили линейно с циклом 15 с (в 1:1 — 22,4 с). Нижняя там возвращалась по двум осям сразу и дёргалась на 12,7 px — это не взято.
- Цвет — эффект Fill на слое рамки.

## Форматы (края в покое, px)

| Формат | Как | Слева | Справа | Сверху | Снизу |
|---|---|---|---|---|---|
| 9:16 | как в пакете | 88 | 77 | 39 (89 у ступеньки) | 76 (124 у ступеньки) |
| 1:1 | квадрат пакета 1440 × 0,75 | 68 | 31 | 9 (38 у ступеньки) | 29 (57 у ступеньки) |
| 16:9 | рамка 9:16, повёрнутая по часовой на четверть: ступеньки на боковых краях | 76 (124) | 39 (89) | 88 | 77 |

## Сверка с эталоном (`node tools/masters/compare.mjs --item SMM_FrameNotched`, 2026-10-23)

- 9:16 в покое — 1,0000; через 15 с мастер стоит там, где пакет через 4 с (первая точка разворота), — 1,0000;
- зелёная и белая (перекрашенный эталон) — 1,0000;
- 1:1 против «Оверлея_1x1», уменьшенного до 1080, — 0,9995;
- порядок кадров (кадр отдельно на свежем проекте) — 1,0 везде.

16:9 в пакете нет: его утверждают по раскадровке.

## Решения по умолчанию (не подписаны)

| Решение | Принято сейчас |
|---|---|
| 16:9 | Повёрнутая рамка 9:16: толщины краёв и ступеньки те же, ступеньки ездят по боковым краям. Растянутый квадратный рисунок дал бы верхний край в 9 px |
| Ход ступенек | Точки разворота пакета (см. выше); размах — как в пакете, а не 20–120 px канона M10: канон для этой рамки задаёт кривую, а размах — её ступеньки |
| Цвета | Три: тёмный пакета, зелёный, белый (из оценки веса T2) |
| 4K | Нет: в каталоге SMM-рамка без 4K |
| Стилл — кадр покоя | Ступеньки на ключе 0 с; петля начинается с того же кадра |
